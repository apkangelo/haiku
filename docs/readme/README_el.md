# Haiku

Διαχειριστής κωδικών πρόσβασης **εκτός σύνδεσης** για Android: οι λειτουργίες του [Bitwarden](https://bitwarden.com) και του
[Keyra](https://github.com/Tahir-1907/Keyra) σε μία εφαρμογή για κινητό, με κινούμενα εφέ GSAP παντού και διεπαφή
που προσαρμόζεται πλήρως μέσω modules. Χωρίς λογαριασμό, χωρίς διακομιστή, χωρίς τηλεμετρία: το θησαυροφυλάκιο δεν φεύγει ποτέ
από το κινητό.

Πακεταρισμένο ως APK με το [Capacitor](https://capacitorjs.com/), μεταγλωττίζεται αυτόματα από το GitHub Actions και είναι σχεδιασμένο για το
Galaxy Z Fold (κλειστό: γραμμή καρτελών· ανοιχτό: πλευρική γραμμή αριστερά και το ανοιχτό στοιχείο δεξιά).

## Λήψη του APK

➡️ **[Λήψη του Haiku (`haiku.apk`)](https://github.com/apk-fold/haiku/raw/main/haiku.apk)** — το αρχείο υπάρχει επίσης στην
καρτέλα *Releases*, μαζί με το άθροισμα SHA-256.

1. Κατέβασε το `haiku.apk` στο κινητό και άνοιξέ το.
2. Επίτρεψε την εγκατάσταση από αυτή την πηγή αν το ζητήσει το Android και πάτησε **Εγκατάσταση**.
3. Στην πρώτη εκκίνηση: *Δημιουργία θησαυροφυλακίου* (ή *Επαναφορά αντιγράφου ασφαλείας*).

Όλες οι εκδόσεις υπογράφονται με **το ίδιο κλειδί** (φάκελος `signing/`): μια ενημέρωση εγκαθίσταται πάνω από την
προηγούμενη χωρίς απεγκατάσταση, άρα χωρίς να χαθεί το θησαυροφυλάκιο. Το κλειδί είναι δημόσιο στο αποθετήριο: εγκατάστησε το Haiku
μόνο από αυτό το αποθετήριο. Για ιδιωτικό κλειδί, πρόσθεσε τα secrets `HAIKU_KEYSTORE_B64`, `HAIKU_KEYSTORE_PASSWORD` και
`HAIKU_KEY_PASSWORD` στο *Settings › Secrets › Actions* (η αλλαγή κλειδιού απαιτεί απεγκατάσταση: κάνε πρώτα
αντίγραφο ασφαλείας).

## Τι κάνει το Haiku

### Θησαυροφυλάκιο
- **7 τύποι στοιχείων**: σύνδεση, κάρτα πληρωμής (κάρτα 3D που γυρίζει για να δεις τον κωδικό ασφαλείας), ταυτότητα, ασφαλής
  σημείωση, κλειδί SSH (δημιουργία Ed25519 σε μορφή OpenSSH), δίκτυο Wi-Fi (κοινοποίηση με κωδικό QR), διακομιστής (αντιγραφή της
  εντολής `ssh`/`sftp`).
- Πολλές **διευθύνσεις ανά σύνδεση** με κανόνα αντιστοίχισης (τομέας, host, ακριβής, κανονική έκφραση…),
  **προσαρμοσμένα πεδία** (κείμενο, κρυφό, ναι/όχι), κρυπτογραφημένα **συνημμένα** (10 MB), **σημειώσεις**.
- **Φάκελοι** (χρώμα, σειρά με σύρσιμο), **ετικέτες** (20 ανά στοιχείο, κανόνες του Keyra), **αγαπημένα**.
- **Αναζήτηση** χωρίς τόνους και πεζά/κεφαλαία, `#étiquette`, `#"deux mots"`, `type:carte`, `is:fav`, `has:totp`, `in:dossier`.
- **Ιστορικό**: 20 εκδόσεις ανά στοιχείο, με δυνατότητα επαναφοράς και σύγκριση πριν/μετά· 10 παλιοί κωδικοί.
- **Κάδος** με αυτόματο άδειασμα (7, 30, 90 ημέρες, 1 έτος ή ποτέ), **συνολικό ιστορικό** των αλλαγών.
- **Επανερώτηση του κύριου κωδικού** ανά στοιχείο (όπως στο Bitwarden), **πολλαπλή επιλογή** (μετακίνηση, αγαπημένα,
  κάδος), **αντιγραφή στοιχείου**, χειρονομίες: σάρωση δεξιά = αντιγραφή, αριστερά = αγαπημένο, παρατεταμένο πάτημα = μενού.
- **Πολλά ανεξάρτητα θησαυροφυλάκια**, το καθένα με τον δικό του κωδικό.

### Αυτόματη συμπλήρωση
- Το Haiku είναι **υπηρεσία αυτόματης συμπλήρωσης του Android** (Ρυθμίσεις › Αυτόματη συμπλήρωση): σε μια εφαρμογή ή έναν
  browser, πάτησε το πεδίο και μετά «Συμπλήρωση με Haiku», ξεκλείδωσε (βιομετρικά, PIN ή κωδικός) και διάλεξε
  τη σύνδεση. Οι αντιστοιχίσεις ακολουθούν τους κανόνες του Bitwarden (τομέας, host, `androidapp://paquet`…), και
  ο συσχετισμός με μια εφαρμογή απομνημονεύεται με ένα άγγιγμα.
- Ο κωδικός 2FA της σύνδεσης αντιγράφεται αυτόματα για το επόμενο βήμα.
- Μετά από μια σύνδεση, το Android προτείνει να **αποθηκευτεί** (ή να ενημερωθεί) η σύνδεση στο Haiku.
- Chrome: *Ρυθμίσεις › Αυτόματη συμπλήρωση › Χρήση άλλης υπηρεσίας*.

### Πιστοποιητής (2FA)
- Κωδικοί **TOTP** (SHA-1/256/512, 6 ή 8 ψηφία, ελεύθερη περίοδος), **HOTP** και **Steam Guard**, ζωντανά με
  δακτύλιο αντίστροφης μέτρησης και τον επόμενο κωδικό.
- Προσθήκη με **σάρωση κωδικού QR** (κάμερα ή στιγμιότυπο οθόνης), χειροκίνητο κλειδί ή σύνδεσμο `otpauth://`.
- Εισαγωγή της εξαγωγής του **Google Authenticator** («Μεταφορά λογαριασμών») και του **Aegis**.

### Γεννήτρια
- Κωδικοί (5 έως 128 χαρακτήρες, ελάχιστα ψηφία/σύμβολα, αποκλεισμός διφορούμενων χαρακτήρων, σύμβολα κατ' επιλογή),
  **φράσεις πρόσβασης** (λίστες 7.776 λέξεων στα γαλλικά και στα αγγλικά), **ονόματα χρήστη** (λέξεις, τυχαία, διεύθυνση
  `moi+xxxx@gmail.com`, τομέας catch-all), **κωδικοί PIN**. Εμφανίζονται η ακριβής εντροπία και ο χρόνος παραβίασης.
- Ιστορικό των τιμών που δημιουργήθηκαν, κρυπτογραφημένο στο θησαυροφυλάκιο.

### Υγεία του θησαυροφυλακίου
Βαθμολογία στα 100 και αναφορές: **αδύναμοι**, **επαναχρησιμοποιημένοι**, **παλιοί** (πάνω από ένα έτος), **ελλείποντες** κωδικοί,
**ιστότοποι με http://**, **ληγμένες κάρτες**, και κατ' απαίτηση: **διαρροές** (Have I Been Pwned, k-ανωνυμία: στέλνονται μόνο
5 χαρακτήρες του hash SHA-1) και **διαθέσιμο αλλά ανενεργό 2FA** (λίστα του 2fa.directory).

### Send (κρυπτογραφημένη κοινοποίηση)
Το αντίστοιχο εκτός σύνδεσης του Bitwarden Send: ένα κείμενο ή ένα αρχείο (15 MB) γίνεται μια κρυπτογραφημένη **αυτόνομη σελίδα HTML**
(AES-256-GCM, PBKDF2-SHA256 με 600.000 επαναλήψεις), με ημερομηνία λήξης. Ο παραλήπτης την ανοίγει σε οποιονδήποτε
browser με τον κωδικό που του δίνεις από άλλο κανάλι.

### Εισαγωγή / εξαγωγή
| Μορφή | Εισαγωγή | Εξαγωγή |
|---|---|---|
| Κρυπτογραφημένο Haiku (`.haiku.json`, Argon2id + AES-256-GCM, ολόκληρο το θησαυροφυλάκιο) | ✅ | ✅ |
| Θησαυροφυλάκιο Haiku (`.haiku`, αντίγραφο ασφαλείας ή άλλο κινητό) | ✅ | ✅ |
| Bitwarden JSON (απλό κείμενο) | ✅ | ✅ |
| Bitwarden JSON **με προστασία κωδικού** (PBKDF2 ή Argon2id) | ✅ | ✅ |
| Bitwarden CSV | ✅ | ✅ |
| Κρυπτογραφημένο Keyra `.mcfexport` | ✅ | ✅ (εισάγεται ξανά στο Keyra) |
| Keyra CSV | ✅ | ✅ |
| KeePassXC CSV, KeePass 2 XML | ✅ | — |
| Chrome / Edge / Brave / Opera, Firefox, Safari / Κωδικοί Apple | ✅ | ✅ (CSV browser) |
| LastPass, 1Password, Dashlane, Proton Pass, NordPass (CSV) | ✅ | — |
| Aegis (απλό JSON), Google Authenticator (QR) | ✅ | ✅ (σύνδεσμοι `otpauth://`) |
| Χάρτινο αντίγραφο (σελίδα HTML για εκτύπωση, όπως το PDF του Keyra) | — | ✅ |

Προεπισκόπηση πριν από την εισαγωγή (χωρίς τους κωδικούς), φάκελοι που δημιουργούνται αυτόματα, παράλειψη διπλοτύπων, υπενθύμιση διαγραφής
των αρχείων απλού κειμένου. Οι τύποι που είναι μόνο του Haiku (Wi-Fi, διακομιστής) περνούν από το Bitwarden και επιστρέφουν χάρη σε ένα πεδίο
`haiku-type`. Η εξαγωγή ζητά ξανά τον κύριο κωδικό.

### Ασφάλεια
```text
κύριος κωδικός ──Argon2id (64 MiB, 3 περάσματα, 4 λωρίδες)──► KEK
KEK ──AES-256-GCM──► DEK (τυχαίο κλειδί δεδομένων 256 bit)
DEK ──AES-256-GCM──► περιεχόμενο θησαυροφυλακίου (συμπιεσμένο JSON)
```
- Ο κύριος κωδικός δεν αποθηκεύεται ποτέ. Η αλλαγή κωδικού απλώς ξανατυλίγει το DEK χωρίς να κρυπτογραφεί τα πάντα από την αρχή.
- Ρυθμιζόμενη αντοχή του Argon2id: ελαφριά (32 MiB), τυπική (64 MiB, όπως το Keyra), ενισχυμένη (128 MiB · 4 περάσματα).
- **Κλειδί ανάκτησης** τύπου Keyra: 32 χαρακτήρες (base32 του Crockford, 150 bit + έλεγχος), εμφανίζεται μόνο
  μία φορά· το «ξέχασα τον κωδικό» δημιουργεί νέο κλειδί και ακυρώνει το παλιό.
- **Βιομετρικά**: το DEK κρυπτογραφείται με κλειδί AES του **Android Keystore** που χρησιμοποιείται μόνο μετά από
  ισχυρό βιομετρικό έλεγχο ταυτότητας, και ακυρώνεται αν προστεθεί νέο δακτυλικό αποτύπωμα.
- **Κωδικός PIN** (4 έως 12 ψηφία) που παράγεται με Argon2id, απενεργοποιείται μετά από 5 λάθη (ρυθμιζόμενο), επιλογή «να ζητείται ξανά ο
  κύριος κωδικός μετά από επανεκκίνηση».
- **Αυτόματο κλείδωμα** (από άμεσα έως 4 ώρες, ή ποτέ), και στο παρασκήνιο· το **πρόχειρο** αδειάζει μετά από
  30 δ (ρυθμιζόμενο) και σημειώνεται ως *ευαίσθητο* (κρυφό στην προεπισκόπηση του Android 13+)· **ασφαλής οθόνη** (χωρίς στιγμιότυπα,
  προεπισκόπηση κρυφή στις πρόσφατες εφαρμογές)· απενεργοποιημένο αντίγραφο ασφαλείας Android του φακέλου της εφαρμογής· APK *release*
  (χωρίς αποσφαλμάτωση).
- Αυτόματα **αντίγραφα ασφαλείας** στο κλείδωμα (αν άλλαξε το θησαυροφυλάκιο) στο `Documents/Haiku/Sauvegardes`, διατηρούνται 10
  (ρυθμιζόμενο)· επαναφέρονται ως **νέο** θησαυροφυλάκιο, τίποτα δεν αντικαθίσταται.

### Προσαρμογή: το Studio και τα modules
- **9 θέματα** (Haïku, Sumi-e, Sakura, Νέον, Matrix, Ηλιακό, Παγετώνας, Χαρτί, Μονόχρωμο), λειτουργίες σκοτεινή, AMOLED,
  φωτεινή και γυάλινη, δύο ελεύθερα χρώματα έμφασης (ή τυχαία αρμονία), κοινοποίηση θέματος με κωδικό.
- **Κινούμενα φόντα**: σέλας, αστερισμός (αντιδρά στο δάχτυλο), μελάνι sumi-e (μια σταγόνα σε κάθε άγγιγμα), πέταλα
  sakura, ρετρό πλέγμα, κυματισμοί, βροχή κώδικα· ένταση, κόκκος χαρτιού, φωτοστέφανο.
- **8 γραμματοσειρές** (Sora, Manrope, Outfit, Space Grotesk, Syne, Unbounded, Shippori Mincho, JetBrains Mono), στρογγύλεμα γωνιών,
  θόλωμα γυαλιού, πυκνότητα, λίστα ως κάρτες / γραμμές / πλέγμα, αρχικά ή εικονίδια.
- Ρυθμιζόμενα **κινούμενα εφέ GSAP** (κανένα, απαλά, κανονικά, *τρελά*): εισαγωγή με τη σφραγίδα 俳句, ensō που ζωγραφίζεται με πινέλο στην
  οθόνη κλειδώματος και λουκέτο που γυρίζει στο ξεκλείδωμα, αποκάλυψη των μυστικών σαν αποκρυπτογράφηση
  (ScrambleText), εκρήξεις σωματιδίων (Physics2D), λίστες που αναδιατάσσονται (Flip), πάνελ και γραμμές που σύρονται
  (Draggable + Inertia), κάρτες που γέρνουν σε 3D, μεταβάσεις σελίδας κατ' επιλογή (ολίσθηση, ζουμ, περιστροφή 3D,
  αυλαία, θόλωμα).
- **Modules**: κάθε λειτουργία (2FA, γεννήτρια, υγεία, Send, φάκελοι, ιστορικό, κάδος, εισαγωγή/εξαγωγή,
  αντίγραφα ασφαλείας) ενεργοποιείται ή απενεργοποιείται· τη **γραμμή καρτελών** τη συνθέτεις εσύ (έως 5, σειρά με σύρσιμο)· η **αρχική**
  αποτελείται από widgets που αναδιατάσσονται (χαϊκού της ημέρας, αναζήτηση, συντομεύσεις, αγαπημένα, κωδικοί 2FA, βαθμολογία υγείας,
  πρόσφατα, γρήγορη γεννήτρια, στατιστικά, φάκελοι, σύννεφο ετικετών).
- **Παλέτα εντολών** (σάρωση προς τα κάτω στην κεφαλίδα, ή Ctrl+K από πληκτρολόγιο) και συντομεύσεις πληκτρολογίου
  (Ctrl+N, Ctrl+L, Ctrl+G, Ctrl+F, Ctrl+,).

## Γνωστοί περιορισμοί
- Χωρίς συγχρονισμό, οργανισμούς ή πρόσβαση έκτακτης ανάγκης (αυτές είναι λειτουργίες του διακομιστή Bitwarden): είναι
  ένα τοπικό θησαυροφυλάκιο, όπως το Keyra. Για να περάσεις από ένα κινητό σε άλλο: αντίγραφο `.haiku` ή κρυπτογραφημένη εξαγωγή.
- Τα passkeys μιας εξαγωγής του Bitwarden δεν εισάγονται: το Haiku δεν είναι πάροχος passkeys.
- Διεπαφή μόνο στα γαλλικά (το Keyra προσφέρει 17 γλώσσες).
- Η αυτόματη συμπλήρωση περνά από την οθόνη του Haiku (χωρίς ενσωματωμένες προτάσεις στο πληκτρολόγιο): ένα άγγιγμα
  παραπάνω, αλλά κανένα μυστικό δεν φυλάσσεται ποτέ σε απλό κείμενο για το σύστημα.
- Τα αρχεία `.kdbx` δεν διαβάζονται απευθείας: κάνε εξαγωγή τους σε CSV ή XML από το KeePassXC / KeePass.
- Η εκτίμηση ισχύος γίνεται εκτός σύνδεσης και είναι κατά προσέγγιση.

## Μεταγλώττιση από εσένα (Windows, Android Studio, JDK 21)
```bash
npm install
npm test                 # δοκιμές του πυρήνα (κρυπτογράφηση, εισαγωγές/εξαγωγές, 2FA…)
npm run android:add      # μόνο αν ο φάκελος android/ δεν υπάρχει
npm run sync             # build web + αντιγραφή στο έργο Android + ρυθμίσεις του Haiku
npm run open             # ανοίγει το Android Studio (ή: cd android && gradlew assembleRelease)
```
Το APK υπογράφεται με το κλειδί του `signing/`, όπως και αυτό του GitHub Actions: εγκαθίστανται το ένα πάνω στο
άλλο.

## Οργάνωση του κώδικα
```text
src/core/      κρυπτογράφηση, θησαυροφυλάκιο, εισαγωγείς/εξαγωγείς, TOTP, γεννήτρια, ισχύς, έλεγχος, Send, SSH
src/views/     οθόνες (αρχική, θησαυροφυλάκιο, στοιχείο, επεξεργασία, 2FA, γεννήτρια, υγεία, Send, Studio, modules…)
src/ui/        εφέ GSAP, κινούμενα φόντα, θέμα, στοιχεία διεπαφής, οθόνη κλειδώματος
scripts/       ρυθμίσεις του έργου Android, εγγενές plugin Java (βιομετρικά Keystore, ασφαλής οθόνη, αυτόματη συμπλήρωση), εικονίδια
tests/         δοκιμές Node (με πραγματική εξαγωγή του Keyra) και δοκιμή διεπαφής με Playwright
```

τις **μορφές εξαγωγής** τους, χωρίς να ξαναχρησιμοποιεί τον κώδικά τους. Ευχαριστώ τα [GSAP](https://gsap.com) (Webflow), [Lucide](https://lucide.dev)
(ISC), [hash-wasm](https://github.com/Daninet/hash-wasm) (MIT), [jsQR](https://github.com/cozmo/jsQR) (Apache-2.0),
[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT), τη λίστα λέξεων του
[EFF](https://www.eff.org/dice) (CC BY 3.0), το [diceware-wordlists-fr](https://github.com/mbelivo/diceware-wordlists-fr)
(βασισμένο στο Lexique 3.81), καθώς και τις γραμματοσειρές Sora, Manrope, Outfit, Space Grotesk, Syne, Unbounded, Shippori Mincho και
