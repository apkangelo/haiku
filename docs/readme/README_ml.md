# Haiku

Android-നുള്ള **ഓഫ്‌ലൈൻ** പാസ്‌വേഡ് മാനേജർ: [Bitwarden](https://bitwarden.com), 
[Keyra](https://github.com/Tahir-1907/Keyra) എന്നിവയുടെ ഫീച്ചറുകൾ ഒരൊറ്റ മൊബൈൽ ആപ്പിൽ, എല്ലായിടത്തും GSAP ആനിമേഷനുകളും
മൊഡ്യൂളുകൾ വഴി പൂർണ്ണമായി ഇഷ്ടാനുസൃതമാക്കാവുന്ന ഇന്റർഫേസും. അക്കൗണ്ടില്ല, സെർവറില്ല, ടെലിമെട്രിയില്ല: വോൾട്ട് ഒരിക്കലും
ഫോൺ വിട്ടുപോകുന്നില്ല.

[Capacitor](https://capacitorjs.com/) ഉപയോഗിച്ച് APK ആയി പാക്ക് ചെയ്തത്, GitHub Actions സ്വയമേവ ബിൽഡ് ചെയ്യുന്നു,
Galaxy Z Fold-നായി രൂപകൽപ്പന ചെയ്തത് (മടക്കിയാൽ: ടാബ് ബാർ; തുറന്നാൽ: ഇടതുവശത്ത് റെയിൽ, വലതുവശത്ത് തുറന്ന ഇനം).

## APK ഡൗൺലോഡ് ചെയ്യുക

➡️ **[Haiku ഡൗൺലോഡ് ചെയ്യുക (`haiku.apk`)](https://github.com/apk-fold/haiku/raw/main/haiku.apk)** — ഫയൽ
*Releases* ടാബിലും SHA-256 ഹാഷിനൊപ്പം ലഭ്യമാണ്.

1. `haiku.apk` ഫോണിൽ ഡൗൺലോഡ് ചെയ്ത് തുറക്കുക.
2. Android ചോദിച്ചാൽ ഈ ഉറവിടത്തിൽ നിന്നുള്ള ഇൻസ്റ്റാളേഷൻ അനുവദിക്കുക, തുടർന്ന് **ഇൻസ്റ്റാൾ ചെയ്യുക** ടാപ്പ് ചെയ്യുക.
3. ആദ്യ തവണ തുറക്കുമ്പോൾ: *എന്റെ വോൾട്ട് സൃഷ്ടിക്കുക* (അല്ലെങ്കിൽ *ബാക്കപ്പ് പുനഃസ്ഥാപിക്കുക*).

എല്ലാ പതിപ്പുകളും **ഒരേ കീ** (`signing/` ഫോൾഡർ) ഉപയോഗിച്ച് സൈൻ ചെയ്തിരിക്കുന്നു: അൺഇൻസ്റ്റാൾ ചെയ്യാതെ തന്നെ അപ്‌ഡേറ്റ്
മുൻ പതിപ്പിന് മുകളിൽ ഇൻസ്റ്റാൾ ആകും, അതിനാൽ വോൾട്ട് നഷ്ടപ്പെടില്ല. ഈ കീ റിപ്പോസിറ്ററിയിൽ പരസ്യമാണ്: Haiku
ഈ റിപ്പോസിറ്ററിയിൽ നിന്ന് മാത്രം ഇൻസ്റ്റാൾ ചെയ്യുക. സ്വകാര്യ കീ ഉപയോഗിക്കാൻ, *Settings › Secrets › Actions*-ൽ `HAIKU_KEYSTORE_B64`, `HAIKU_KEYSTORE_PASSWORD`,
`HAIKU_KEY_PASSWORD` എന്നീ secrets ചേർക്കുക (കീ മാറ്റിയാൽ അൺഇൻസ്റ്റാൾ ചെയ്യേണ്ടിവരും: ആദ്യം
ബാക്കപ്പ് എടുക്കുക).

## Haiku എന്തൊക്കെ ചെയ്യുന്നു

### വോൾട്ട്
- **7 തരം ഇനങ്ങൾ**: ലോഗിൻ, പേയ്‌മെന്റ് കാർഡ് (സുരക്ഷാ കോഡ് കാണാൻ മറിക്കാവുന്ന 3D കാർഡ്), ഐഡന്റിറ്റി, സുരക്ഷിത
  കുറിപ്പ്, SSH കീ (OpenSSH ഫോർമാറ്റിൽ Ed25519 നിർമ്മാണം), Wi-Fi നെറ്റ്‌വർക്ക് (QR കോഡ് വഴി പങ്കിടൽ), സെർവർ (
  `ssh`/`sftp` കമാൻഡ് പകർത്തൽ).
- പൊരുത്ത നിയമത്തോടെ (ഡൊമെയ്ൻ, ഹോസ്റ്റ്, കൃത്യം, റെഗുലർ എക്‌സ്‌പ്രഷൻ…) **ഓരോ ലോഗിനും ഒന്നിലധികം വിലാസങ്ങൾ**,
  **ഇഷ്ടാനുസൃത ഫീൽഡുകൾ** (ടെക്‌സ്റ്റ്, മറച്ചത്, അതെ/ഇല്ല), എൻക്രിപ്റ്റ് ചെയ്ത **അറ്റാച്ച്‌മെന്റുകൾ** (10 MB), **കുറിപ്പുകൾ**.
- **ഫോൾഡറുകൾ** (നിറം, വലിച്ചിട്ട് ക്രമീകരിക്കൽ), **ടാഗുകൾ** (ഓരോ ഇനത്തിനും 20, Keyra-യുടെ നിയമങ്ങൾ), **പ്രിയപ്പെട്ടവ**.
- ഉച്ചാരണചിഹ്നങ്ങളും വലിയ/ചെറിയ അക്ഷരങ്ങളും പരിഗണിക്കാത്ത **തിരയൽ**, `#étiquette`, `#"deux mots"`, `type:carte`, `is:fav`, `has:totp`, `in:dossier`.
- **ചരിത്രം**: ഓരോ ഇനത്തിനും 20 പതിപ്പുകൾ, മുമ്പ്/ശേഷം താരതമ്യത്തോടെ പുനഃസ്ഥാപിക്കാം; 10 പഴയ പാസ്‌വേഡുകൾ.
- സ്വയമേവ ശൂന്യമാകുന്ന **ട്രാഷ്** (7, 30, 90 ദിവസം, 1 വർഷം അല്ലെങ്കിൽ ഒരിക്കലുമില്ല), മാറ്റങ്ങളുടെ **മൊത്തം ചരിത്രം**.
- ഓരോ ഇനത്തിനും **മാസ്റ്റർ പാസ്‌വേഡ് വീണ്ടും ചോദിക്കൽ** (Bitwarden പോലെ), **ഒന്നിലധികം തിരഞ്ഞെടുക്കൽ** (നീക്കുക, പ്രിയപ്പെട്ടവ,
  ട്രാഷ്), **ഡ്യൂപ്ലിക്കേറ്റ്**, ജെസ്‌ചറുകൾ: വലത്തേക്ക് സ്വൈപ്പ് = പകർത്തുക, ഇടത്തേക്ക് = പ്രിയപ്പെട്ടത്, നീണ്ട അമർത്തൽ = മെനു.
- സ്വന്തം പാസ്‌വേഡുള്ള **ഒന്നിലധികം സ്വതന്ത്ര വോൾട്ടുകൾ**.

### ഓട്ടോഫിൽ
- Haiku ഒരു **Android ഓട്ടോഫിൽ സേവനമാണ്** (ക്രമീകരണങ്ങൾ › ഓട്ടോഫിൽ): ഒരു ആപ്പിലോ
  ബ്രൗസറിലോ ഫീൽഡിൽ ടാപ്പ് ചെയ്ത് "Haiku ഉപയോഗിച്ച് പൂരിപ്പിക്കുക", അൺലോക്ക് ചെയ്ത് (ബയോമെട്രിക്സ്, PIN അല്ലെങ്കിൽ പാസ്‌വേഡ്)
  ലോഗിൻ തിരഞ്ഞെടുക്കുക. പൊരുത്തപ്പെടുത്തൽ Bitwarden-ന്റെ നിയമങ്ങൾ പിന്തുടരുന്നു (ഡൊമെയ്ൻ, ഹോസ്റ്റ്, `androidapp://paquet`…),
  ഒരു ആപ്പുമായുള്ള ബന്ധം ഒറ്റ ടാപ്പിൽ ഓർമ്മിക്കാം.
- ലോഗിനിന്റെ 2FA കോഡ് അടുത്ത ഘട്ടത്തിനായി സ്വയമേവ പകർത്തുന്നു.
- ലോഗിൻ ചെയ്ത ശേഷം, ലോഗിൻ Haiku-ൽ **സേവ് ചെയ്യാൻ** (അല്ലെങ്കിൽ അപ്‌ഡേറ്റ് ചെയ്യാൻ) Android നിർദ്ദേശിക്കുന്നു.
- Chrome: *ക്രമീകരണങ്ങൾ › ഓട്ടോഫിൽ › മറ്റൊരു സേവനം ഉപയോഗിക്കുക*.

### ഓതന്റിക്കേറ്റർ (2FA)
- **TOTP** കോഡുകൾ (SHA-1/256/512, 6 അല്ലെങ്കിൽ 8 അക്കം, ഇഷ്ടമുള്ള കാലയളവ്), **HOTP**, **Steam Guard**, തത്സമയം,
  കൗണ്ട്‌ഡൗൺ വളയവും അടുത്ത കോഡും സഹിതം.
- **QR കോഡ് സ്കാൻ ചെയ്ത്** (ക്യാമറ അല്ലെങ്കിൽ സ്ക്രീൻഷോട്ട്), കീ നേരിട്ട് നൽകി, അല്ലെങ്കിൽ `otpauth://` ലിങ്ക് വഴി ചേർക്കാം.
- **Google Authenticator** എക്‌സ്‌പോർട്ടും ("അക്കൗണ്ടുകൾ കൈമാറുക") **Aegis**-ഉം ഇമ്പോർട്ട് ചെയ്യാം.

### ജനറേറ്റർ
- പാസ്‌വേഡുകൾ (5 മുതൽ 128 വരെ അക്ഷരങ്ങൾ, കുറഞ്ഞ അക്ക/ചിഹ്ന എണ്ണം, ആശയക്കുഴപ്പമുണ്ടാക്കുന്ന അക്ഷരങ്ങൾ ഒഴിവാക്കൽ, ഇഷ്ടമുള്ള ചിഹ്നങ്ങൾ),
  **പാസ്‌ഫ്രേസുകൾ** (ഫ്രഞ്ചിലും ഇംഗ്ലീഷിലും 7,776 വാക്കുകളുടെ പട്ടികകൾ), **ഉപയോക്തൃനാമങ്ങൾ** (വാക്കുകൾ, ക്രമരഹിതം, വിലാസം
  `moi+xxxx@gmail.com`, catch-all ഡൊമെയ്ൻ), **PIN കോഡുകൾ**. കൃത്യമായ എൻട്രോപ്പിയും തകർക്കാനുള്ള സമയവും കാണിക്കുന്നു.
- സൃഷ്ടിച്ച മൂല്യങ്ങളുടെ ചരിത്രം, വോൾട്ടിൽ എൻക്രിപ്റ്റ് ചെയ്ത് സൂക്ഷിക്കുന്നു.

### വോൾട്ടിന്റെ ആരോഗ്യം
100-ൽ സ്കോറും റിപ്പോർട്ടുകളും: **ദുർബലമായ**, **വീണ്ടും ഉപയോഗിച്ച**, **പഴയ** (ഒരു വർഷത്തിലധികം), **ഇല്ലാത്ത** പാസ്‌വേഡുകൾ,
**http:// സൈറ്റുകൾ**, **കാലഹരണപ്പെട്ട കാർഡുകൾ**, ആവശ്യപ്പെട്ടാൽ: **ചോർച്ചകൾ** (Have I Been Pwned, k-അജ്ഞാതത്വം: SHA-1 ഹാഷിന്റെ
5 അക്ഷരങ്ങൾ മാത്രമേ അയയ്ക്കൂ), **ലഭ്യമായിട്ടും ഓണാക്കാത്ത 2FA** (2fa.directory പട്ടിക).

### Send (എൻക്രിപ്റ്റ് ചെയ്ത പങ്കിടൽ)
Bitwarden Send-ന്റെ ഓഫ്‌ലൈൻ പതിപ്പ്: ഒരു ടെക്‌സ്റ്റോ ഫയലോ (15 MB) എൻക്രിപ്റ്റ് ചെയ്ത ഒരു **സ്വയംപര്യാപ്ത HTML പേജ്** ആയി മാറുന്നു
(AES-256-GCM, PBKDF2-SHA256 600,000 ആവർത്തനങ്ങൾ), കാലഹരണ തീയതിയോടെ. മറ്റൊരു മാർഗ്ഗത്തിലൂടെ നിങ്ങൾ നൽകുന്ന പാസ്‌വേഡ് ഉപയോഗിച്ച്
സ്വീകർത്താവിന് ഏത് ബ്രൗസറിലും അത് തുറക്കാം.

ഇമ്പോർട്ടിന് മുമ്പുള്ള പ്രിവ്യൂ (പാസ്‌വേഡുകൾ ഇല്ലാതെ), ഫോൾഡറുകൾ സ്വയമേവ സൃഷ്ടിക്കുന്നു, ഡ്യൂപ്ലിക്കേറ്റുകൾ ഒഴിവാക്കുന്നു, പ്ലെയിൻ ടെക്‌സ്റ്റ് ഫയലുകൾ
ഇല്ലാതാക്കാനുള്ള ഓർമ്മപ്പെടുത്തൽ. Haiku-യുടെ സ്വന്തം തരങ്ങൾ (Wi-Fi, സെർവർ) ഒരു `haiku-type` ഫീൽഡിന്റെ സഹായത്തോടെ
Bitwarden വഴി പോയി തിരികെ വരുമ്പോഴും നഷ്ടപ്പെടുന്നില്ല. എക്‌സ്‌പോർട്ട് മാസ്റ്റർ പാസ്‌വേഡ് വീണ്ടും ചോദിക്കുന്നു.

### സുരക്ഷ
```text
മാസ്റ്റർ പാസ്‌വേഡ് ──Argon2id (64 MiB, 3 പാസുകൾ, 4 ലെയ്നുകൾ)──► KEK
KEK ──AES-256-GCM──► DEK (ക്രമരഹിതമായ 256-ബിറ്റ് ഡാറ്റ കീ)
DEK ──AES-256-GCM──► വോൾട്ട് ഉള്ളടക്കം (കംപ്രസ് ചെയ്ത JSON)
```
- മാസ്റ്റർ പാസ്‌വേഡ് ഒരിക്കലും സൂക്ഷിക്കുന്നില്ല. പാസ്‌വേഡ് മാറ്റുന്നത് എല്ലാം വീണ്ടും എൻക്രിപ്റ്റ് ചെയ്യാതെ DEK മാത്രം വീണ്ടും പൊതിയുന്നു.
- ക്രമീകരിക്കാവുന്ന Argon2id ശക്തി: ലഘു (32 MiB), സ്റ്റാൻഡേർഡ് (64 MiB, Keyra പോലെ), ശക്തിപ്പെടുത്തിയത് (128 MiB · 4 പാസുകൾ).
- Keyra ശൈലിയിലുള്ള **റിക്കവറി കീ**: 32 അക്ഷരങ്ങൾ (Crockford base32, 150 ബിറ്റ് + പരിശോധന), ഒരിക്കൽ മാത്രം
  കാണിക്കുന്നു; "പാസ്‌വേഡ് മറന്നു" പുതിയ കീ സൃഷ്ടിക്കുകയും പഴയത് അസാധുവാക്കുകയും ചെയ്യുന്നു.
- **ബയോമെട്രിക്സ്**: ശക്തമായ ബയോമെട്രിക് പ്രാമാണീകരണത്തിന് ശേഷം മാത്രം ഉപയോഗിക്കാവുന്ന ഒരു **Android Keystore** AES കീ ഉപയോഗിച്ച് DEK
  എൻക്രിപ്റ്റ് ചെയ്യുന്നു; പുതിയ വിരലടയാളം ചേർത്താൽ അത് അസാധുവാകും.
- Argon2id വഴി ഉണ്ടാക്കിയ **PIN കോഡ്** (4 മുതൽ 12 അക്കം വരെ), 5 പിശകുകൾക്ക് ശേഷം നിർജ്ജീവമാക്കുന്നു (ക്രമീകരിക്കാം), "റീസ്റ്റാർട്ടിന് ശേഷം
  മാസ്റ്റർ പാസ്‌വേഡ് വീണ്ടും ചോദിക്കുക" ഓപ്ഷൻ.
- **ഓട്ടോ-ലോക്ക്** (ഉടനടി മുതൽ 4 മണിക്കൂർ വരെ, അല്ലെങ്കിൽ ഒരിക്കലുമില്ല), പശ്ചാത്തലത്തിലും; **ക്ലിപ്പ്‌ബോർഡ്**
  30 സെ. കഴിഞ്ഞ് മായ്ക്കുന്നു (ക്രമീകരിക്കാം), *സെൻസിറ്റീവ്* എന്ന് അടയാളപ്പെടുത്തുന്നു (Android 13+ പ്രിവ്യൂവിൽ മറച്ചത്); **സുരക്ഷിത സ്ക്രീൻ** (സ്ക്രീൻഷോട്ടുകൾ ഇല്ല,
  സമീപകാല ആപ്പുകളിൽ പ്രിവ്യൂ മറച്ചത്); ആപ്പ് ഫോൾഡറിന്റെ Android ബാക്കപ്പ് പ്രവർത്തനരഹിതം; *release* APK
  (ഡീബഗ് ചെയ്യാനാകില്ല).
- ലോക്ക് ചെയ്യുമ്പോൾ (വോൾട്ട് മാറിയിട്ടുണ്ടെങ്കിൽ) `Documents/Haiku/Sauvegardes`-ൽ സ്വയമേവയുള്ള **ബാക്കപ്പുകൾ**, 10 എണ്ണം സൂക്ഷിക്കുന്നു
  (ക്രമീകരിക്കാം); അവ **പുതിയ** വോൾട്ടായി പുനഃസ്ഥാപിക്കപ്പെടുന്നു, ഒന്നും മായ്ച്ചെഴുതുന്നില്ല.

### വ്യക്തിഗതമാക്കൽ: സ്റ്റുഡിയോയും മൊഡ്യൂളുകളും
- **9 തീമുകൾ** (Haïku, Sumi-e, Sakura, Neon, Matrix, Solar, Glacier, Paper, Monochrome), ഡാർക്ക്, AMOLED,
  ലൈറ്റ്, ഗ്ലാസ് മോഡുകൾ, രണ്ട് ഇഷ്ട ആക്‌സന്റ് നിറങ്ങൾ (അല്ലെങ്കിൽ ക്രമരഹിത സംയോജനം), കോഡ് വഴി തീം പങ്കിടൽ.
- **ആനിമേറ്റഡ് പശ്ചാത്തലങ്ങൾ**: ധ്രുവദീപ്തി, നക്ഷത്രസമൂഹം (വിരലിനോട് പ്രതികരിക്കുന്നു), സുമി-ഇ മഷി (ഓരോ സ്പർശത്തിലും ഒരു തുള്ളി), സകുര
  ഇതളുകൾ, റെട്രോ ഗ്രിഡ്, തരംഗങ്ങൾ, കോഡ് മഴ; തീവ്രത, പേപ്പർ ഘടന, പ്രഭാവലയം.
- **8 ഫോണ്ടുകൾ** (Sora, Manrope, Outfit, Space Grotesk, Syne, Unbounded, Shippori Mincho, JetBrains Mono), കോണുകളുടെ വളവ്,
  ഗ്ലാസ് മങ്ങൽ, സാന്ദ്രത, കാർഡുകൾ / വരികൾ / ഗ്രിഡ് ആയി ലിസ്റ്റ്, ആദ്യാക്ഷരങ്ങൾ അല്ലെങ്കിൽ ഐക്കണുകൾ.
- ക്രമീകരിക്കാവുന്ന **GSAP ആനിമേഷനുകൾ** (ഒന്നുമില്ല, മൃദുവായ, സാധാരണ, *അടിപൊളി*): 俳句 മുദ്രയോടെയുള്ള ഇൻട്രോ, ലോക്ക് സ്ക്രീനിൽ ബ്രഷ് കൊണ്ട്
  വരയ്ക്കുന്ന എൻസോ, അൺലോക്ക് ചെയ്യുമ്പോൾ തിരിയുന്ന പൂട്ട്, ഡീക്രിപ്റ്റ് ചെയ്യുന്നതുപോലെ രഹസ്യങ്ങൾ വെളിപ്പെടുത്തൽ
  (ScrambleText), കണികാ സ്ഫോടനങ്ങൾ (Physics2D), സ്വയം പുനഃക്രമീകരിക്കുന്ന ലിസ്റ്റുകൾ (Flip), വലിച്ചുനീക്കാവുന്ന പാനലുകളും വരികളും
  (Draggable + Inertia), 3D-യിൽ ചരിയുന്ന കാർഡുകൾ, ഇഷ്ടമുള്ള പേജ് ട്രാൻസിഷനുകൾ (സ്ലൈഡ്, സൂം, 3D ഫ്ലിപ്പ്,
  തിരശ്ശീല, മങ്ങൽ).
- **മൊഡ്യൂളുകൾ**: ഓരോ ഫീച്ചറും (2FA, ജനറേറ്റർ, ആരോഗ്യം, Send, ഫോൾഡറുകൾ, ചരിത്രം, ട്രാഷ്, ഇമ്പോർട്ട്/എക്‌സ്‌പോർട്ട്,
  ബാക്കപ്പുകൾ) ഓൺ/ഓഫ് ചെയ്യാം; **ടാബ് ബാർ** നിങ്ങൾ തന്നെ ഒരുക്കുന്നു (പരമാവധി 5, വലിച്ചിട്ട് ക്രമീകരിക്കാം); **ഹോം**
  പുനഃക്രമീകരിക്കാവുന്ന വിജറ്റുകൾ കൊണ്ട് നിർമ്മിച്ചതാണ് (ഇന്നത്തെ ഹൈക്കു, തിരയൽ, കുറുക്കുവഴികൾ, പ്രിയപ്പെട്ടവ, 2FA കോഡുകൾ, ആരോഗ്യ സ്കോർ,
  സമീപകാല ഇനങ്ങൾ, ദ്രുത ജനറേറ്റർ, സ്ഥിതിവിവരക്കണക്കുകൾ, ഫോൾഡറുകൾ, ടാഗ് ക്ലൗഡ്).
- **കമാൻഡ് പാലറ്റ്** (ഹെഡറിൽ താഴേക്ക് സ്വൈപ്പ് ചെയ്യുക, അല്ലെങ്കിൽ കീബോർഡിൽ Ctrl+K) കൂടാതെ കീബോർഡ് കുറുക്കുവഴികൾ
  (Ctrl+N, Ctrl+L, Ctrl+G, Ctrl+F, Ctrl+,).

## അറിയപ്പെടുന്ന പരിമിതികൾ
- സിങ്ക്, ഓർഗനൈസേഷനുകൾ, അടിയന്തര ആക്‌സസ് എന്നിവ ഇല്ല (ഇവ Bitwarden സെർവറിന്റെ ഫീച്ചറുകളാണ്): ഇത്
  Keyra പോലെ ഒരു ലോക്കൽ വോൾട്ടാണ്. ഒരു ഫോണിൽ നിന്ന് മറ്റൊന്നിലേക്ക് മാറാൻ: `.haiku` ബാക്കപ്പ് അല്ലെങ്കിൽ എൻക്രിപ്റ്റ് ചെയ്ത എക്‌സ്‌പോർട്ട്.
- Bitwarden എക്‌സ്‌പോർട്ടിലെ പാസ്‌കീകൾ ഇമ്പോർട്ട് ചെയ്യുന്നില്ല: Haiku ഒരു പാസ്‌കീ ദാതാവല്ല.
- ഇന്റർഫേസ് ഫ്രഞ്ചിൽ മാത്രം (Keyra 17 ഭാഷകൾ നൽകുന്നു).
- ഓട്ടോഫിൽ Haiku-യുടെ സ്ക്രീനിലൂടെയാണ് (കീബോർഡിൽ ഇൻലൈൻ നിർദ്ദേശങ്ങളില്ല): ഒരു ടാപ്പ് കൂടുതൽ,
  പക്ഷേ ഒരു രഹസ്യവും സിസ്റ്റത്തിനായി പ്ലെയിൻ ടെക്‌സ്റ്റായി ഒരിക്കലും സൂക്ഷിക്കുന്നില്ല.
- `.kdbx` ഫയലുകൾ നേരിട്ട് വായിക്കുന്നില്ല: KeePassXC / KeePass-ൽ നിന്ന് അവ CSV അല്ലെങ്കിൽ XML ആയി എക്‌സ്‌പോർട്ട് ചെയ്യുക.
- ശക്തി കണക്കാക്കൽ ഓഫ്‌ലൈനാണ്, ഏകദേശ മൂല്യം മാത്രം.

## സ്വയം ബിൽഡ് ചെയ്യാൻ (Windows, Android Studio, JDK 21)
```bash
npm install
npm test                 # കോർ ടെസ്റ്റുകൾ (എൻക്രിപ്ഷൻ, ഇമ്പോർട്ട്/എക്‌സ്‌പോർട്ട്, 2FA…)
npm run android:add      # android/ ഫോൾഡർ ഇല്ലെങ്കിൽ മാത്രം
npm run sync             # വെബ് ബിൽഡ് + Android പ്രോജക്റ്റിലേക്ക് പകർത്തൽ + Haiku ക്രമീകരണങ്ങൾ
npm run open             # Android Studio തുറക്കുന്നു (അല്ലെങ്കിൽ: cd android && gradlew assembleRelease)
```
GitHub Actions-ന്റേത് പോലെ തന്നെ APK `signing/`-ലെ കീ ഉപയോഗിച്ച് സൈൻ ചെയ്യുന്നു: രണ്ടും ഒന്നിനുമുകളിൽ മറ്റൊന്നായി
ഇൻസ്റ്റാൾ ചെയ്യാം.

## കടപ്പാട്
