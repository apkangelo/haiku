# Haiku

**Офлайн**-менеджер паролів для Android: можливості [Bitwarden](https://bitwarden.com) і
[Keyra](https://github.com/Tahir-1907/Keyra) в одному мобільному застосунку, з анімаціями GSAP усюди та інтерфейсом,
який повністю налаштовується модулями. Ні облікового запису, ні сервера, ні телеметрії: сховище ніколи не покидає
телефон.

Запаковано в APK за допомогою [Capacitor](https://capacitorjs.com/), автоматично збирається через GitHub Actions і створено для
Galaxy Z Fold (у складеному стані — панель вкладок; у розкладеному — бічна панель ліворуч і відкритий запис праворуч).

## Завантажити APK

➡️ **[Завантажити Haiku (`haiku.apk`)](https://github.com/apk-fold/haiku/raw/main/haiku.apk)** — файл також є на вкладці
*Releases* разом із контрольною сумою SHA-256.

1. Завантаж `haiku.apk` на телефон і відкрий його.
2. Якщо Android попросить, дозволь установлення з цього джерела, потім натисни **Установити**.
3. Під час першого запуску: *Створити сховище* (або *Відновити резервну копію*).

Усі версії підписані **одним і тим самим ключем** (тека `signing/`): оновлення встановлюється поверх
попередньої версії без видалення, тож сховище не втрачається. Цей ключ відкрито лежить у репозиторії: встановлюй Haiku
лише з цього репозиторію. Для приватного ключа додай секрети `HAIKU_KEYSTORE_B64`, `HAIKU_KEYSTORE_PASSWORD` і
`HAIKU_KEY_PASSWORD` у *Settings › Secrets › Actions* (зміна ключа вимагає видалення застосунку: спершу зроби
резервну копію).

## Що вміє Haiku

### Сховище
- **7 типів записів**: логін, банківська картка (3D-картка, яку можна перевернути, щоб побачити CVC), особисті дані, захищена
  нотатка, SSH-ключ (генерація Ed25519 у форматі OpenSSH), мережа Wi-Fi (поширення через QR-код), сервер (копіювання
  команди `ssh`/`sftp`).
- Кілька **адрес на логін** із правилом зіставлення (домен, хост, точний збіг, регулярний вираз…),
  **власні поля** (текст, приховане, так/ні), зашифровані **вкладення** (10 МБ), **нотатки**.
- **Теки** (колір, порядок перетягуванням), **теги** (20 на запис, правила Keyra), **обране**.
- **Пошук** без урахування діакритики й регістру, `#étiquette`, `#"deux mots"`, `type:carte`, `is:fav`, `has:totp`, `in:dossier`.
- **Історія**: 20 версій на запис, які можна відновити з порівнянням «до/після»; 10 попередніх паролів.
- **Кошик** з автоматичним очищенням (7, 30, 90 днів, 1 рік або ніколи), **загальна історія** змін.
- **Повторний запит головного пароля** для окремого запису (як у Bitwarden), **множинний вибір** (переміщення, обране,
  кошик), **дублювання**, жести: свайп праворуч — копіювати, ліворуч — в обране, довге натискання — меню.
- **Кілька незалежних сховищ**, у кожного свій пароль.

### Автозаповнення
- Haiku — це **служба автозаповнення Android** (Налаштування › Автозаповнення): у застосунку або
  браузері торкнися поля, потім «Заповнити з Haiku», розблокуй (біометрія, PIN-код або пароль) і вибери
  логін. Зіставлення відбувається за правилами Bitwarden (домен, хост, `androidapp://paquet`…), а
  зв'язок із застосунком можна запам'ятати одним дотиком.
- Код 2FA логіна автоматично копіюється для наступного кроку.
- Після входу Android пропонує **зберегти** (або оновити) логін у Haiku.
- Chrome: *Налаштування › Автозаповнення › Використовувати інший сервіс*.

### Автентифікатор (2FA)
- Коди **TOTP** (SHA-1/256/512, 6 або 8 цифр, будь-який період), **HOTP** і **Steam Guard** у реальному часі, з
  кільцем зворотного відліку та наступним кодом.
- Додавання **скануванням QR-коду** (камера або знімок екрана), введенням ключа вручну або посиланням `otpauth://`.
- Імпорт експорту **Google Authenticator** («Перенесення облікових записів») і **Aegis**.

### Генератор
- Паролі (від 5 до 128 символів, мінімум цифр/символів, без схожих символів, вибір символів),
  **парольні фрази** (списки з 7776 слів французькою та англійською), **імена користувачів** (слова, випадкові, адреса
  `moi+xxxx@gmail.com`, домен catch-all), **PIN-коди**. Показуються точна ентропія та час злому.
- Історія згенерованих значень, зашифрована в сховищі.

### Стан сховища
Оцінка зі 100 і звіти: **слабкі**, **повторювані**, **старі** (понад рік), **відсутні** паролі,
**сайти на http://**, **прострочені картки**, а на запит — **витоки** (Have I Been Pwned, k-анонімність: надсилаються
лише 5 символів хешу SHA-1) і **доступна, але не ввімкнена 2FA** (список 2fa.directory).

### Send (зашифроване поширення)
Офлайн-аналог Bitwarden Send: текст або файл (15 МБ) перетворюється на зашифровану **самодостатню HTML-сторінку**
(AES-256-GCM, PBKDF2-SHA256, 600 000 ітерацій) з терміном дії. Одержувач відкриває її в будь-якому
браузері з паролем, який ти передаєш йому іншим каналом.

Попередній перегляд перед імпортом (без паролів), автоматичне створення тек, пропуск дублікатів, нагадування видалити
файли у відкритому вигляді. Власні типи Haiku (Wi-Fi, сервер) переживають шлях туди й назад через Bitwarden завдяки полю
`haiku-type`. Експорт знову запитує головний пароль.

### Безпека
```text
головний пароль ──Argon2id (64 МіБ, 3 проходи, 4 потоки)──► KEK
KEK ──AES-256-GCM──► DEK (випадковий 256-бітний ключ даних)
DEK ──AES-256-GCM──► вміст сховища (стиснений JSON)
```
- Головний пароль ніколи не зберігається. Зміна пароля лише перепаковує DEK, не перешифровуючи все.
- Налаштовувана стійкість Argon2id: легка (32 МіБ), стандартна (64 МіБ, як у Keyra), посилена (128 МіБ · 4 проходи).
- **Ключ відновлення** у стилі Keyra: 32 символи (base32 Крокфорда, 150 біт + контроль), показується лише
  один раз; «забув пароль» створює новий ключ і робить старий недійсним.
- **Біометрія**: DEK зашифровано AES-ключем з **Android Keystore**, який можна використати лише після
  надійної біометричної автентифікації; ключ анулюється, якщо додано новий відбиток.
- **PIN-код** (від 4 до 12 цифр), похідний через Argon2id, вимикається після 5 помилок (налаштовується), опція «знову запитувати
  головний пароль після перезапуску».
- **Автоблокування** (від негайного до 4 год або ніколи), зокрема у фоні; **буфер обміну** очищується через
  30 с (налаштовується) і позначається як *конфіденційний* (прихований у превʼю Android 13+); **захищений екран** (без знімків екрана,
  превʼю приховане в недавніх застосунках); резервне копіювання теки застосунку засобами Android вимкнено; APK у режимі *release*
  (без налагодження).
- Автоматичні **резервні копії** під час блокування (якщо сховище змінилося) у `Documents/Haiku/Sauvegardes`, зберігаються 10
  (налаштовується); вони відновлюються як **нове** сховище, нічого не перезаписується.

### Персоналізація: Студія та модулі
- **9 тем** (Haïku, Sumi-e, Sakura, Неон, Матриця, Сонце, Льодовик, Папір, Монохром), режими темний, AMOLED,
  світлий і скло, два вільні акцентні кольори (або випадкова гармонія), поширення теми через код.
- **Анімовані фони**: полярне сяйво, сузір'я (реагує на палець), туш сумі-е (крапля від кожного дотику), пелюстки
  сакури, ретро-сітка, хвилі, дощ коду; інтенсивність, зернистість паперу, ореол.
- **8 шрифтів** (Sora, Manrope, Outfit, Space Grotesk, Syne, Unbounded, Shippori Mincho, JetBrains Mono), заокруглення,
  розмиття скла, щільність, список картками / рядками / сіткою, ініціали або значки.
- Налаштовувані **анімації GSAP** (немає, м'які, звичайні, *шалені*): вступ із печаткою 俳句, енсо, намальоване пензлем на
  екрані блокування, і замок, що повертається під час розблокування, розкриття секретів як під час розшифрування
  (ScrambleText), вибухи частинок (Physics2D), списки, що самі перебудовуються (Flip), панелі й рядки, які можна перетягувати
  (Draggable + Inertia), картки, що нахиляються в 3D, переходи між сторінками на вибір (зсув, масштаб, 3D-перевертання,
  завіса, розмиття).
- **Модулі**: кожну функцію (2FA, генератор, стан, Send, теки, історія, кошик, імпорт/експорт,
  резервні копії) можна ввімкнути або вимкнути; **панель вкладок** складається на смак (не більше 5, порядок перетягуванням); **головний екран**
  складається з віджетів, які можна переставляти (хайку дня, пошук, ярлики, обране, коди 2FA, оцінка стану,
  недавні, швидкий генератор, статистика, теки, хмара тегів).
- **Палітра команд** (свайп униз по заголовку або Ctrl+K на клавіатурі) і комбінації клавіш
  (Ctrl+N, Ctrl+L, Ctrl+G, Ctrl+F, Ctrl+,).

## Відомі обмеження
- Немає синхронізації, організацій та екстреного доступу (це функції сервера Bitwarden): це
  локальне сховище, як Keyra. Щоб перейти з одного телефона на інший: резервна копія `.haiku` або зашифрований експорт.
- Ключі доступу (passkeys) з експорту Bitwarden не імпортуються: Haiku не є постачальником ключів доступу.
- Інтерфейс лише французькою (Keyra пропонує 17 мов).
- Автозаповнення проходить через екран Haiku (без вбудованих підказок у клавіатурі): на один дотик більше,
  зате жоден секрет ніколи не зберігається для системи у відкритому вигляді.
- Файли `.kdbx` не читаються напряму: експортуй їх у CSV або XML з KeePassXC / KeePass.
- Оцінка стійкості виконується офлайн і є приблизною.

## Зібрати самостійно (Windows, Android Studio, JDK 21)
```bash
npm install
npm test                 # тести ядра (шифрування, імпорт/експорт, 2FA…)
npm run android:add      # лише якщо теки android/ ще немає
npm run sync             # веб-збірка + копіювання в Android-проєкт + налаштування Haiku
npm run open             # відкриває Android Studio (або: cd android && gradlew assembleRelease)
```
APK підписується ключем із `signing/`, як і збірка GitHub Actions: обидві встановлюються одна поверх
одної.

## Будова коду
```text
src/core/      шифрування, сховище, імпорт/експорт, TOTP, генератор, стійкість, аудит, Send, SSH
src/views/     екрани (головна, сховище, запис, редагування, 2FA, генератор, стан, Send, Студія, модулі…)
src/ui/        ефекти GSAP, анімовані фони, тема, компоненти, екран блокування
scripts/       налаштування Android-проєкту, нативний плагін на Java (біометрія Keystore, захищений екран, автозаповнення), значки
tests/         тести Node (зі справжнім експортом Keyra) і тест інтерфейсу на Playwright
```

## Подяки

їхні **формати експорту**, не використовуючи їхнього коду. Дякую [GSAP](https://gsap.com) (Webflow), [Lucide](https://lucide.dev)
(ISC), [hash-wasm](https://github.com/Daninet/hash-wasm) (MIT), [jsQR](https://github.com/cozmo/jsQR) (Apache-2.0),

[EFF](https://www.eff.org/dice) (CC BY 3.0), [diceware-wordlists-fr](https://github.com/mbelivo/diceware-wordlists-fr)
(на основі Lexique 3.81), а також шрифтам Sora, Manrope, Outfit, Space Grotesk, Syne, Unbounded, Shippori Mincho і
