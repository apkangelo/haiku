# Haiku

مدير كلمات مرور يعمل **دون اتصال** على Android: ميزات [Bitwarden](https://bitwarden.com) و
[Keyra](https://github.com/Tahir-1907/Keyra) في تطبيق جوّال واحد، مع حركات GSAP في كل مكان وواجهة
قابلة للتخصيص بالكامل عبر الوحدات. لا حساب ولا خادم ولا قياس عن بُعد: الخزنة لا تغادر
الهاتف أبدًا.

مُغلَّف كملف APK باستخدام [Capacitor](https://capacitorjs.com/)، ويُبنى تلقائيًا عبر GitHub Actions، ومصمَّم لهاتف
Galaxy Z Fold (مطويًا: شريط الألسنة؛ مفتوحًا: شريط جانبي على اليسار والعنصر المفتوح على اليمين).

## تنزيل ملف APK

➡️ **[تنزيل Haiku (`haiku.apk`)](https://github.com/apk-fold/haiku/raw/main/haiku.apk)** — الملف موجود أيضًا في تبويب
*Releases* مع بصمة SHA-256 الخاصة به.

1. نزّل `haiku.apk` على الهاتف وافتحه.
2. اسمح بالتثبيت من هذا المصدر إذا طلب Android ذلك، ثم اضغط **تثبيت**.
3. عند التشغيل الأول: *إنشاء خزنتي* (أو *استعادة نسخة احتياطية*).

جميع الإصدارات موقّعة **بالمفتاح نفسه** (المجلد `signing/`): يُثبَّت التحديث فوق الإصدار
السابق دون إلغاء التثبيت، أي دون فقدان الخزنة. هذا المفتاح علني في المستودع: لا تثبّت Haiku
إلا من هذا المستودع. لاستخدام مفتاح خاص، أضف الأسرار `HAIKU_KEYSTORE_B64` و`HAIKU_KEYSTORE_PASSWORD` و
`HAIKU_KEY_PASSWORD` في *Settings › Secrets › Actions* (تغيير المفتاح يستلزم إلغاء التثبيت: خذ
نسخة احتياطية أولًا).

## ما الذي يفعله Haiku

### الخزنة
- **7 أنواع من العناصر**: بيانات تسجيل الدخول، بطاقة دفع (بطاقة ثلاثية الأبعاد تُقلب لرؤية رمز الأمان)، الهوية، ملاحظة
  آمنة، مفتاح SSH (توليد Ed25519 بصيغة OpenSSH)، شبكة Wi-Fi (مشاركة عبر رمز QR)، خادم (نسخ
  الأمر `ssh`/`sftp`).
- عدة **عناوين لكل بيانات دخول** مع قاعدة مطابقة (النطاق، المضيف، تطابق تام، تعبير نمطي…)،
  **حقول مخصصة** (نص، مخفي، نعم/لا)، **مرفقات** مشفّرة (10 ميغابايت)، **ملاحظات**.
- **مجلدات** (لون، ترتيب بالسحب)، **وسوم** (20 لكل عنصر، وفق قواعد Keyra)، **مفضلة**.
- **بحث** لا يميّز علامات التشكيل وحالة الأحرف، `#étiquette` و`#"deux mots"` و`type:carte` و`is:fav` و`has:totp` و`in:dossier`.
- **السجل**: 20 نسخة لكل عنصر، قابلة للاستعادة مع مقارنة قبل/بعد؛ و10 كلمات مرور قديمة.
- **سلة محذوفات** تُفرَّغ تلقائيًا (7 أو 30 أو 90 يومًا، أو سنة، أو أبدًا)، و**سجل عام** للتعديلات.
- **إعادة طلب كلمة المرور الرئيسية** لكل عنصر (كما في Bitwarden)، **تحديد متعدد** (نقل، مفضلة،
  سلة المحذوفات)، **نسخ العنصر**، الإيماءات: السحب لليمين = نسخ، لليسار = مفضلة، الضغط المطوّل = القائمة.
- **عدة خزائن مستقلة**، لكل منها كلمة مرورها.

### الملء التلقائي
- Haiku **خدمة ملء تلقائي في Android** (الإعدادات › الملء التلقائي): في تطبيق أو
  متصفح، المس الحقل ثم «الملء باستخدام Haiku»، وافتح القفل (القياسات الحيوية أو PIN أو كلمة المرور) واختر
  بيانات الدخول. تتبع المطابقة قواعد Bitwarden (النطاق، المضيف، `androidapp://paquet`…)، ويمكن
  تذكّر الربط مع تطبيق بلمسة واحدة.
- يُنسخ رمز 2FA الخاص ببيانات الدخول تلقائيًا للخطوة التالية.
- بعد تسجيل الدخول، يقترح Android **حفظ** بيانات الدخول (أو تحديثها) في Haiku.
- Chrome: *الإعدادات › الملء التلقائي › استخدام خدمة أخرى*.

### أداة المصادقة (2FA)
- رموز **TOTP** (SHA-1/256/512، من 6 أو 8 أرقام، بفترة حرة)، و**HOTP** و**Steam Guard**، مباشرةً مع
  حلقة عدّ تنازلي والرمز التالي.
- الإضافة عبر **مسح رمز QR** (الكاميرا أو لقطة شاشة)، أو مفتاح يدوي، أو رابط `otpauth://`.
- استيراد تصدير **Google Authenticator** («نقل الحسابات») و**Aegis**.

### المولّد
- كلمات مرور (من 5 إلى 128 حرفًا، حد أدنى من الأرقام/الرموز، استبعاد الأحرف الملتبسة، رموز حسب الاختيار)،
  **عبارات مرور** (قوائم من 7776 كلمة بالفرنسية والإنجليزية)، **أسماء مستخدمين** (كلمات، عشوائية، عنوان
  `moi+xxxx@gmail.com`، نطاق catch-all)، **رموز PIN**. تُعرض الإنتروبيا الدقيقة ومدة الكسر.
- سجل القيم المولَّدة، مشفّر داخل الخزنة.

### صحة الخزنة
درجة من 100 وتقارير: كلمات مرور **ضعيفة**، **مكررة**، **قديمة** (أكثر من سنة)، **مفقودة**،
**مواقع http://**، **بطاقات منتهية الصلاحية**، وعند الطلب: **التسريبات** (Have I Been Pwned، إخفاء الهوية k-anonymity: لا يُرسل إلا
5 أحرف من بصمة SHA-1) و**2FA متاحة لكنها غير مفعّلة** (قائمة 2fa.directory).

### Send (مشاركة مشفّرة)
المقابل غير المتصل لـ Bitwarden Send: يتحول نص أو ملف (15 ميغابايت) إلى **صفحة HTML مستقلة** مشفّرة
(AES-256-GCM، وPBKDF2-SHA256 بـ 600,000 تكرار)، مع تاريخ انتهاء. يفتحها المستلم في أي
متصفح بكلمة المرور التي ترسلها إليه عبر قناة أخرى.

معاينة قبل الاستيراد (دون كلمات المرور)، وإنشاء المجلدات تلقائيًا، وتجاهل المكررات، وتذكير بحذف
الملفات الصريحة. الأنواع الخاصة بـ Haiku (Wi-Fi، خادم) تذهب وتعود عبر Bitwarden دون فقدان بفضل حقل
`haiku-type`. يطلب التصدير كلمة المرور الرئيسية مجددًا.

### الأمان
```text
كلمة المرور الرئيسية ──Argon2id (64 MiB، 3 تمريرات، 4 مسارات)──► KEK
KEK ──AES-256-GCM──► DEK (مفتاح بيانات عشوائي 256 بت)
DEK ──AES-256-GCM──► محتوى الخزنة (JSON مضغوط)
```
- لا تُخزَّن كلمة المرور الرئيسية أبدًا. تغيير كلمة المرور يعيد تغليف DEK دون إعادة تشفير كل شيء.
- قوة Argon2id قابلة للضبط: خفيفة (32 MiB)، قياسية (64 MiB، كما في Keyra)، معزّزة (128 MiB · 4 تمريرات).
- **مفتاح استرداد** على طريقة Keyra: ‏32 حرفًا (base32 الخاص بـ Crockford، ‏150 بت + تحقق)، يُعرض مرة
  واحدة فقط؛ و«نسيت كلمة المرور» تنشئ مفتاحًا جديدًا وتُبطل القديم.
- **القياسات الحيوية**: يُشفَّر DEK بمفتاح AES من **Android Keystore** لا يمكن استخدامه إلا بعد
  مصادقة حيوية قوية، ويُبطَل إذا أُضيفت بصمة جديدة.
- **رمز PIN** (من 4 إلى 12 رقمًا) مشتق عبر Argon2id، يُعطَّل بعد 5 أخطاء (قابل للضبط)، مع خيار «طلب
  كلمة المرور الرئيسية مجددًا بعد إعادة التشغيل».
- **قفل تلقائي** (من فوري حتى 4 ساعات، أو أبدًا)، وفي الخلفية أيضًا؛ **الحافظة** تُمسح بعد
  30 ثانية (قابل للضبط) وتُعلَّم بأنها *حساسة* (مخفية في معاينة Android 13+)؛ **شاشة آمنة** (لا لقطات شاشة،
  ومعاينة مخفية في التطبيقات الأخيرة)؛ تعطيل نسخ Android الاحتياطي لمجلد التطبيق؛ ملف APK بنسخة *release*
  (غير قابل للتصحيح).
- **نسخ احتياطية** تلقائية عند القفل (إذا تغيّرت الخزنة) في `Documents/Haiku/Sauvegardes`، يُحتفظ بـ 10 منها
  (قابل للضبط)؛ وتُستعاد كخزنة **جديدة** دون استبدال أي شيء.

### التخصيص: الاستوديو والوحدات
- **9 سمات** (Haïku، Sumi-e، Sakura، نيون، ماتريكس، شمسية، جليدية، ورقية، أحادية اللون)، أوضاع: داكن، AMOLED،
  فاتح وزجاجي، لونا تمييز حرّان (أو تناغم عشوائي)، ومشاركة السمة عبر رمز.
- **خلفيات متحركة**: شفق، كوكبة (تتفاعل مع الإصبع)، حبر سومي-إي (قطرة مع كل لمسة)، بتلات
  ساكورا، شبكة كلاسيكية، تموجات، مطر الشيفرة؛ الشدة، حبيبات الورق، الهالة.
- **8 خطوط** (Sora، Manrope، Outfit، Space Grotesk، Syne، Unbounded، Shippori Mincho، JetBrains Mono)، استدارة الزوايا،
  تمويه الزجاج، الكثافة، القائمة كبطاقات / صفوف / شبكة، الأحرف الأولى أو الأيقونات.
- **حركات GSAP** قابلة للضبط (لا شيء، هادئة، عادية، *جنونية*): مقدمة بختم 俳句، ودائرة إنسو تُرسم بالفرشاة على
  شاشة القفل وقفل يدور عند فتحه، وكشف الأسرار كأنها تُفك شيفرتها
  (ScrambleText)، وانفجارات جسيمات (Physics2D)، وقوائم تعيد ترتيب نفسها (Flip)، ولوحات وصفوف قابلة للسحب
  (Draggable + Inertia)، وبطاقات تميل بالأبعاد الثلاثية، وانتقالات صفحات حسب الاختيار (انزلاق، تكبير، قلب ثلاثي الأبعاد،
  ستارة، تمويه).
- **الوحدات**: يمكن تفعيل كل ميزة أو تعطيلها (2FA، المولّد، الصحة، Send، المجلدات، السجل، سلة المحذوفات، الاستيراد/التصدير،
  النسخ الاحتياطية)؛ وتؤلّف **شريط الألسنة** بنفسك (5 كحد أقصى، ترتيب بالسحب)؛ وتتكوّن **الصفحة الرئيسية**
  من أدوات قابلة لإعادة الترتيب (هايكو اليوم، البحث، الاختصارات، المفضلة، رموز 2FA، درجة الصحة،
  الأحدث، مولّد سريع، إحصاءات، مجلدات، سحابة الوسوم).
- **لوحة الأوامر** (السحب للأسفل على الترويسة، أو Ctrl+K من لوحة المفاتيح) واختصارات لوحة المفاتيح
  (Ctrl+N، Ctrl+L، Ctrl+G، Ctrl+F، Ctrl+,).

## القيود المعروفة
- لا مزامنة ولا مؤسسات ولا وصول طارئ (هذه ميزات خادم Bitwarden): إنها
  خزنة محلية، مثل Keyra. للانتقال من هاتف إلى آخر: نسخة `.haiku` الاحتياطية أو تصدير مشفّر.
- لا تُستورد مفاتيح المرور (passkeys) من تصدير Bitwarden: Haiku ليس مزوّدًا لمفاتيح المرور.
- الواجهة بالفرنسية فقط (يقدّم Keyra ‏17 لغة).
- يمر الملء التلقائي عبر شاشة Haiku (لا اقتراحات مدمجة في لوحة المفاتيح): لمسة إضافية،
  لكن لا يُحفظ أي سر أبدًا كنص صريح لصالح النظام.
- لا تُقرأ ملفات `.kdbx` مباشرة: صدّرها بصيغة CSV أو XML من KeePassXC / KeePass.
- تقدير قوة كلمة المرور يُحسب دون اتصال وهو تقريبي.

## البناء بنفسك (Windows، Android Studio، JDK 21)
```bash
npm install
npm test                 # اختبارات النواة (التشفير، الاستيراد/التصدير، 2FA…)
npm run android:add      # فقط إذا لم يكن المجلد android/ موجودًا
npm run sync             # بناء الويب + النسخ إلى مشروع Android + إعدادات Haiku
npm run open             # يفتح Android Studio (أو: cd android && gradlew assembleRelease)
```
يُوقَّع ملف APK بالمفتاح الموجود في `signing/`، تمامًا مثل ملف GitHub Actions: يمكن تثبيت كل منهما فوق
الآخر.

## تنظيم الشيفرة
```text
src/core/      التشفير، الخزنة، المستوردات/المصدّرات، TOTP، المولّد، القوة، التدقيق، Send، SSH
src/views/     الشاشات (الرئيسية، الخزنة، العنصر، التحرير، 2FA، المولّد، الصحة، Send، الاستوديو، الوحدات…)
src/ui/        تأثيرات GSAP، الخلفيات المتحركة، السمة، المكوّنات، شاشة القفل
scripts/       إعدادات مشروع Android، إضافة Java أصلية (قياسات Keystore الحيوية، الشاشة الآمنة، الملء التلقائي)، الأيقونات
tests/         اختبارات Node (بتصدير حقيقي من Keyra) واختبار واجهة عبر Playwright
```
