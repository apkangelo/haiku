# Haiku

**Офлайн**-менеджер паролей для Android: возможности [Bitwarden](https://bitwarden.com) и
[Keyra](https://github.com/Tahir-1907/Keyra) в одном мобильном приложении, с анимациями GSAP повсюду и интерфейсом,
который полностью настраивается с помощью модулей. Ни аккаунта, ни сервера, ни телеметрии: хранилище никогда не покидает
телефон.

Упаковано в APK с помощью [Capacitor](https://capacitorjs.com/), автоматически собирается через GitHub Actions и рассчитано на
Galaxy Z Fold (в сложенном виде — панель вкладок, в разложенном — боковая панель слева и открытая запись справа).

## Скачать APK

➡️ **[Скачать Haiku (`haiku.apk`)](https://github.com/apk-fold/haiku/raw/main/haiku.apk)** — файл также лежит на вкладке
*Releases* вместе с контрольной суммой SHA-256.

1. Скачай `haiku.apk` на телефон и открой его.
2. Если Android попросит, разреши установку из этого источника, затем нажми **Установить**.
3. При первом запуске: *Создать хранилище* (или *Восстановить резервную копию*).

Все версии подписаны **одним и тем же ключом** (папка `signing/`): обновление ставится поверх
предыдущей версии без удаления, а значит, без потери хранилища. Этот ключ открыто лежит в репозитории: устанавливай Haiku
только из этого репозитория. Для закрытого ключа добавь секреты `HAIKU_KEYSTORE_B64`, `HAIKU_KEYSTORE_PASSWORD` и
`HAIKU_KEY_PASSWORD` в *Settings › Secrets › Actions* (смена ключа требует удаления приложения: сначала сделай
резервную копию).

## Что умеет Haiku

### Хранилище
- **7 типов записей**: логин, банковская карта (3D-карточка, которую можно перевернуть, чтобы увидеть CVC), личные данные, защищённая
  заметка, SSH-ключ (генерация Ed25519 в формате OpenSSH), сеть Wi-Fi (передача через QR-код), сервер (копирование
  команды `ssh`/`sftp`).
- Несколько **адресов на логин** с правилом сопоставления (домен, хост, точное совпадение, регулярное выражение…),
  **свои поля** (текст, скрытое, да/нет), зашифрованные **вложения** (10 МБ), **заметки**.
- **Папки** (цвет, порядок перетаскиванием), **теги** (20 на запись, правила Keyra), **избранное**.
- **Поиск** без учёта диакритики и регистра, `#étiquette`, `#"deux mots"`, `type:carte`, `is:fav`, `has:totp`, `in:dossier`.
- **История**: 20 версий на запись, восстанавливаемых со сравнением «до/после»; 10 прежних паролей.
- **Корзина** с автоматической очисткой (7, 30, 90 дней, 1 год или никогда), **общая история** изменений.
- **Повторный запрос мастер-пароля** для отдельной записи (как в Bitwarden), **множественный выбор** (перемещение, избранное,
  корзина), **дублирование**, жесты: свайп вправо — копировать, влево — в избранное, долгое нажатие — меню.
- **Несколько независимых хранилищ**, у каждого свой пароль.

### Автозаполнение
- Haiku — это **служба автозаполнения Android** (Настройки › Автозаполнение): в приложении или
  браузере коснись поля, затем «Заполнить с Haiku», разблокируй (биометрия, PIN-код или пароль) и выбери
  логин. Сопоставление следует правилам Bitwarden (домен, хост, `androidapp://paquet`…), а
  связь с приложением можно запомнить одним касанием.
- Код 2FA для логина автоматически копируется для следующего шага.
- После входа Android предлагает **сохранить** (или обновить) логин в Haiku.
- Chrome: *Настройки › Автозаполнение › Использовать другой сервис*.

### Аутентификатор (2FA)
- Коды **TOTP** (SHA-1/256/512, 6 или 8 цифр, любой период), **HOTP** и **Steam Guard** в реальном времени, с
  кольцом обратного отсчёта и следующим кодом.
- Добавление через **сканирование QR-кода** (камера или снимок экрана), ввод ключа вручную или ссылку `otpauth://`.
- Импорт экспорта **Google Authenticator** («Перенос аккаунтов») и **Aegis**.

### Генератор
- Пароли (от 5 до 128 символов, минимум цифр/символов, без похожих символов, выбор символов),
  **парольные фразы** (списки из 7776 слов на французском и английском), **имена пользователей** (слова, случайные, адрес
  `moi+xxxx@gmail.com`, домен catch-all), **PIN-коды**. Показываются точная энтропия и время взлома.
- История сгенерированных значений, зашифрованная в хранилище.

### Здоровье хранилища
Оценка из 100 и отчёты: **слабые**, **повторяющиеся**, **старые** (старше года), **отсутствующие** пароли,
**сайты на http://**, **просроченные карты**, а по запросу — **утечки** (Have I Been Pwned, k-анонимность: отправляются
только 5 символов хеша SHA-1) и **доступная, но не включённая 2FA** (список 2fa.directory).

### Send (зашифрованная передача)
Офлайн-аналог Bitwarden Send: текст или файл (15 МБ) превращается в зашифрованную **самодостаточную HTML-страницу**
(AES-256-GCM, PBKDF2-SHA256, 600 000 итераций) со сроком действия. Получатель открывает её в любом
браузере с паролем, который ты передаёшь ему по другому каналу.

### Импорт / экспорт
| Формат | Импорт | Экспорт |
|---|---|---|
| Зашифрованный Haiku (`.haiku.json`, Argon2id + AES-256-GCM, всё хранилище) | ✅ | ✅ |
| Хранилище Haiku (`.haiku`, резервная копия или другой телефон) | ✅ | ✅ |
| Bitwarden JSON (открытый текст) | ✅ | ✅ |
| Bitwarden JSON, **защищённый паролем** (PBKDF2 или Argon2id) | ✅ | ✅ |
| Bitwarden CSV | ✅ | ✅ |
| Зашифрованный Keyra `.mcfexport` | ✅ | ✅ (снова импортируется в Keyra) |
| Keyra CSV | ✅ | ✅ |
| KeePassXC CSV, KeePass 2 XML | ✅ | — |
| Chrome / Edge / Brave / Opera, Firefox, Safari / Пароли Apple | ✅ | ✅ (CSV браузера) |
| LastPass, 1Password, Dashlane, Proton Pass, NordPass (CSV) | ✅ | — |
| Aegis (открытый JSON), Google Authenticator (QR) | ✅ | ✅ (ссылки `otpauth://`) |

Предпросмотр перед импортом (без паролей), автоматическое создание папок, пропуск дубликатов, напоминание удалить
файлы в открытом виде. Собственные типы Haiku (Wi-Fi, сервер) переживают путь туда и обратно через Bitwarden благодаря полю
`haiku-type`. Экспорт заново запрашивает мастер-пароль.

### Безопасность
```text
мастер-пароль ──Argon2id (64 МиБ, 3 прохода, 4 потока)──► KEK
KEK ──AES-256-GCM──► DEK (случайный 256-битный ключ данных)
DEK ──AES-256-GCM──► содержимое хранилища (сжатый JSON)
```
- Мастер-пароль никогда не хранится. Смена пароля лишь перешифровывает DEK, не перешифровывая всё остальное.
- Настраиваемая стойкость Argon2id: лёгкая (32 МиБ), стандартная (64 МиБ, как в Keyra), усиленная (128 МиБ · 4 прохода).
- **Ключ восстановления** в стиле Keyra: 32 символа (base32 Крокфорда, 150 бит + контроль), показывается только
  один раз; «забыл пароль» создаёт новый ключ и делает старый недействительным.
- **Биометрия**: DEK зашифрован AES-ключом из **Android Keystore**, который можно использовать только после
  надёжной биометрической аутентификации; он аннулируется при добавлении нового отпечатка.
- **PIN-код** (от 4 до 12 цифр), выведенный через Argon2id, отключается после 5 ошибок (настраивается), опция «снова спрашивать
  мастер-пароль после перезагрузки».
- **Автоблокировка** (от немедленной до 4 ч, или никогда), в том числе в фоне; **буфер обмена** очищается через
  30 с (настраивается) и помечается как *конфиденциальный* (скрыт в превью Android 13+); **защищённый экран** (без снимков экрана,
  превью скрыто в списке недавних приложений); резервное копирование папки приложения средствами Android отключено; APK в режиме *release*
  (без отладки).
- Автоматические **резервные копии** при блокировке (если хранилище изменилось) в `Documents/Haiku/Sauvegardes`, хранятся 10
  (настраивается); они восстанавливаются как **новое** хранилище, ничего не перезаписывается.

### Оформление: Студия и модули
- **9 тем** (Haïku, Sumi-e, Sakura, Неон, Матрица, Солнце, Ледник, Бумага, Монохром), режимы тёмный, AMOLED,
  светлый и стекло, два свободных акцентных цвета (или случайная гармония), обмен темой через код.
- **Анимированные фоны**: полярное сияние, созвездие (реагирует на палец), тушь сумиэ (капля при каждом касании), лепестки
  сакуры, ретро-сетка, волны, дождь кода; интенсивность, зернистость бумаги, ореол.
- **8 шрифтов** (Sora, Manrope, Outfit, Space Grotesk, Syne, Unbounded, Shippori Mincho, JetBrains Mono), скругления,
  размытие стекла, плотность, список карточками / строками / сеткой, инициалы или значки.
- Настраиваемые **анимации GSAP** (нет, мягкие, обычные, *безумные*): вступление с печатью 俳句, энсо, рисуемое кистью на
  экране блокировки, и замок, поворачивающийся при разблокировке, раскрытие секретов как при расшифровке
  (ScrambleText), взрывы частиц (Physics2D), списки, которые сами перестраиваются (Flip), перетаскиваемые панели и строки
  (Draggable + Inertia), карточки, наклоняющиеся в 3D, переходы между страницами на выбор (сдвиг, масштаб, 3D-переворот,
  занавес, размытие).
- **Модули**: каждую функцию (2FA, генератор, здоровье, Send, папки, история, корзина, импорт/экспорт,
  резервные копии) можно включить или выключить; **панель вкладок** собирается по вкусу (не больше 5, порядок перетаскиванием); **главный экран**
  состоит из виджетов, которые можно переставлять (хайку дня, поиск, ярлыки, избранное, коды 2FA, оценка здоровья,
  недавние, быстрый генератор, статистика, папки, облако тегов).
- **Палитра команд** (свайп вниз по заголовку или Ctrl+K на клавиатуре) и сочетания клавиш
  (Ctrl+N, Ctrl+L, Ctrl+G, Ctrl+F, Ctrl+,).

## Известные ограничения
- Нет синхронизации, организаций и экстренного доступа (это функции сервера Bitwarden): это
  локальное хранилище, как Keyra. Чтобы перейти с одного телефона на другой: резервная копия `.haiku` или зашифрованный экспорт.
- Ключи доступа (passkeys) из экспорта Bitwarden не импортируются: Haiku не является поставщиком ключей доступа.
- Интерфейс только на французском (Keyra предлагает 17 языков).
- Автозаполнение проходит через экран Haiku (без встроенных подсказок в клавиатуре): на одно касание больше,
  зато ни один секрет никогда не хранится для системы в открытом виде.
- Файлы `.kdbx` напрямую не читаются: экспортируй их в CSV или XML из KeePassXC / KeePass.
- Оценка стойкости выполняется офлайн и приблизительна.

## Собрать самому (Windows, Android Studio, JDK 21)
```bash
npm install
npm test                 # тесты ядра (шифрование, импорт/экспорт, 2FA…)
npm run android:add      # только если папки android/ ещё нет
npm run sync             # веб-сборка + копирование в Android-проект + настройки Haiku
npm run open             # открывает Android Studio (или: cd android && gradlew assembleRelease)
```
APK подписывается ключом из `signing/`, как и сборка GitHub Actions: обе ставятся поверх
друг друга.

## Устройство кода
```text
src/core/      шифрование, хранилище, импорт/экспорт, TOTP, генератор, стойкость, аудит, Send, SSH
src/views/     экраны (главная, хранилище, запись, редактирование, 2FA, генератор, здоровье, Send, Студия, модули…)
src/ui/        эффекты GSAP, анимированные фоны, тема, компоненты, экран блокировки
scripts/       настройки Android-проекта, нативный плагин на Java (биометрия Keystore, защищённый экран, автозаполнение), значки
tests/         тесты Node (с настоящим экспортом Keyra) и тест интерфейса на Playwright
```
