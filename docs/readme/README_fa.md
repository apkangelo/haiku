# Haiku

مدیر رمز عبور **آفلاین** برای Android: قابلیت‌های [Bitwarden](https://bitwarden.com) و
[Keyra](https://github.com/Tahir-1907/Keyra) در یک برنامهٔ موبایل، با انیمیشن‌های GSAP در همه‌جا و رابطی
که با ماژول‌ها کاملاً شخصی‌سازی می‌شود. بدون حساب، بدون سرور، بدون تله‌متری: گاوصندوق هرگز از گوشی
بیرون نمی‌رود.

با [Capacitor](https://capacitorjs.com/) به APK تبدیل شده، به‌طور خودکار با GitHub Actions ساخته می‌شود و برای
Galaxy Z Fold طراحی شده است (در حالت بسته: نوار زبانه‌ها؛ در حالت باز: ریل در سمت چپ و مورد باز در سمت راست).

## دانلود APK

➡️ **[دانلود Haiku (`haiku.apk`)](https://github.com/apk-fold/haiku/raw/main/haiku.apk)** — فایل در زبانهٔ
*Releases* هم همراه با چکیدهٔ SHA-256 موجود است.

1. `haiku.apk` را روی گوشی دانلود کنید و بازش کنید.
2. اگر Android خواست، نصب از این منبع را مجاز کنید و سپس **نصب** را بزنید.
3. در نخستین اجرا: *ساختن گاوصندوق من* (یا *بازیابی نسخهٔ پشتیبان*).

همهٔ نسخه‌ها با **یک کلید واحد** (پوشهٔ `signing/`) امضا شده‌اند: به‌روزرسانی بدون حذف روی نسخهٔ
قبلی نصب می‌شود، پس گاوصندوق از دست نمی‌رود. این کلید در مخزن عمومی است: Haiku را فقط
از همین مخزن نصب کنید. برای کلید خصوصی، رازهای `HAIKU_KEYSTORE_B64`، `HAIKU_KEYSTORE_PASSWORD` و
`HAIKU_KEY_PASSWORD` را در *Settings › Secrets › Actions* اضافه کنید (تغییر کلید به حذف برنامه نیاز دارد: اول
نسخهٔ پشتیبان بگیرید).

## Haiku چه کار می‌کند

### گاوصندوق
- **۷ نوع مورد**: اطلاعات ورود، کارت پرداخت (کارت سه‌بعدی که برای دیدن کد امنیتی برگردانده می‌شود)، هویت، یادداشت
  امن، کلید SSH (ساخت Ed25519 در قالب OpenSSH)، شبکهٔ Wi-Fi (اشتراک با کد QR)، سرور (کپی
  فرمان `ssh`/`sftp`).
- چند **نشانی برای هر ورود** با قاعدهٔ تطبیق (دامنه، میزبان، دقیق، عبارت منظم…)،
  **فیلدهای سفارشی** (متن، پنهان، بله/خیر)، **پیوست‌های** رمزنگاری‌شده (۱۰ مگابایت)، **یادداشت‌ها**.
- **پوشه‌ها** (رنگ، مرتب‌سازی با کشیدن)، **برچسب‌ها** (۲۰ برچسب برای هر مورد، طبق قواعد Keyra)، **علاقه‌مندی‌ها**.
- **جست‌وجو** بدون حساسیت به اعراب و بزرگی/کوچکی حروف، `#étiquette`، `#"deux mots"`، `type:carte`، `is:fav`، `has:totp`، `in:dossier`.
- **تاریخچه**: ۲۰ نسخه برای هر مورد، قابل بازیابی با مقایسهٔ پیش/پس؛ ۱۰ گذرواژهٔ قدیمی.
- **سطل زباله** با پاک‌سازی خودکار (۷، ۳۰، ۹۰ روز، ۱ سال یا هرگز)، **تاریخچهٔ کلی** تغییرات.
- **درخواست دوبارهٔ گذرواژهٔ اصلی** برای هر مورد (مانند Bitwarden)، **انتخاب چندتایی** (جابه‌جایی، علاقه‌مندی‌ها،
  سطل زباله)، **تکثیر**، اشاره‌ها: کشیدن به راست = کپی، به چپ = علاقه‌مندی، نگه داشتن طولانی = منو.
- **چند گاوصندوق مستقل**، هر کدام با گذرواژهٔ خودش.

### پرکردن خودکار
- Haiku یک **سرویس پرکردن خودکار Android** است (تنظیمات › پرکردن خودکار): در یک برنامه یا
  مرورگر، روی فیلد بزنید و سپس «پرکردن با Haiku»، قفل را باز کنید (زیست‌سنجی، PIN یا گذرواژه) و
  اطلاعات ورود را انتخاب کنید. تطبیق‌ها از قواعد Bitwarden پیروی می‌کنند (دامنه، میزبان، `androidapp://paquet`…) و
  پیوند با یک برنامه با یک لمس به خاطر سپرده می‌شود.
- کد 2FA مربوط به ورود برای مرحلهٔ بعد خودکار کپی می‌شود.
- پس از ورود، Android پیشنهاد می‌دهد اطلاعات ورود در Haiku **ذخیره** (یا به‌روز) شود.
- Chrome: *تنظیمات › پرکردن خودکار › استفاده از سرویسی دیگر*.

### احرازگر (2FA)
- کدهای **TOTP** (SHA-1/256/512، ۶ یا ۸ رقم، دورهٔ آزاد)، **HOTP** و **Steam Guard**، به‌صورت زنده با
  حلقهٔ شمارش معکوس و کد بعدی.
- افزودن با **اسکن کد QR** (دوربین یا تصویر صفحه)، کلید دستی یا پیوند `otpauth://`.
- وارد کردن خروجی **Google Authenticator** («انتقال حساب‌ها») و **Aegis**.

### تولیدکننده
- گذرواژه‌ها (۵ تا ۱۲۸ نویسه، حداقل تعداد رقم/نماد، حذف نویسه‌های مبهم، نمادهای دلخواه)،
  **عبارت‌های عبور** (فهرست‌های ۷۷۷۶ واژه‌ای به فرانسوی و انگلیسی)، **نام‌های کاربری** (واژه‌ها، تصادفی، نشانی
  `moi+xxxx@gmail.com`، دامنهٔ catch-all)، **کدهای PIN**. آنتروپی دقیق و زمان شکستن نمایش داده می‌شود.
- تاریخچهٔ مقادیر تولیدشده، رمزنگاری‌شده در گاوصندوق.

### سلامت گاوصندوق
امتیاز از ۱۰۰ و گزارش‌ها: گذرواژه‌های **ضعیف**، **تکراری**، **قدیمی** (بیش از یک سال)، **خالی**،
**سایت‌های http://**، **کارت‌های منقضی**، و در صورت درخواست: **نشت‌ها** (Have I Been Pwned، k-ناشناسی: فقط
۵ نویسه از چکیدهٔ SHA-1 فرستاده می‌شود) و **2FA در دسترس ولی غیرفعال** (فهرست 2fa.directory).

### Send (اشتراک رمزنگاری‌شده)
معادل آفلاین Bitwarden Send: یک متن یا فایل (۱۵ مگابایت) به یک **صفحهٔ HTML مستقل** رمزنگاری‌شده تبدیل می‌شود
(AES-256-GCM، PBKDF2-SHA256 با ۶۰۰٬۰۰۰ تکرار)، با تاریخ انقضا. گیرنده آن را در هر
مرورگری با گذرواژه‌ای که از راهی دیگر به او می‌دهید باز می‌کند.

### ورود / خروج داده
| قالب | ورود | خروج |
|---|---|---|
| Haiku رمزنگاری‌شده (`.haiku.json`، Argon2id + AES-256-GCM، کل گاوصندوق) | ✅ | ✅ |
| گاوصندوق Haiku (`.haiku`، نسخهٔ پشتیبان یا گوشی دیگر) | ✅ | ✅ |
| Bitwarden JSON (متن ساده) | ✅ | ✅ |
| Bitwarden JSON **محافظت‌شده با گذرواژه** (PBKDF2 یا Argon2id) | ✅ | ✅ |
| Bitwarden CSV | ✅ | ✅ |
| Keyra `.mcfexport` رمزنگاری‌شده | ✅ | ✅ (دوباره در Keyra وارد می‌شود) |
| Keyra CSV | ✅ | ✅ |
| KeePassXC CSV، KeePass 2 XML | ✅ | — |
| Chrome / Edge / Brave / Opera، Firefox، Safari / گذرواژه‌های Apple | ✅ | ✅ (CSV مرورگر) |
| LastPass، 1Password، Dashlane، Proton Pass، NordPass (CSV) | ✅ | — |
| Aegis (JSON ساده)، Google Authenticator (QR) | ✅ | ✅ (پیوندهای `otpauth://`) |
| نسخهٔ کاغذی (صفحهٔ HTML برای چاپ، مانند PDF در Keyra) | — | ✅ |

پیش‌نمایش پیش از ورود (بدون گذرواژه‌ها)، ساخت خودکار پوشه‌ها، نادیده گرفتن موارد تکراری، یادآوری برای حذف
فایل‌های متن ساده. انواع ویژهٔ Haiku (Wi-Fi، سرور) به لطف فیلد `haiku-type` رفت‌وبرگشت از طریق Bitwarden را
بی‌آسیب طی می‌کنند. خروج داده دوباره گذرواژهٔ اصلی را می‌خواهد.

### امنیت
```text
گذرواژهٔ اصلی ──Argon2id (64 MiB، ۳ گذر، ۴ مسیر)──► KEK
KEK ──AES-256-GCM──► DEK (کلید دادهٔ تصادفی ۲۵۶ بیتی)
DEK ──AES-256-GCM──► محتوای گاوصندوق (JSON فشرده)
```
- گذرواژهٔ اصلی هرگز ذخیره نمی‌شود. تغییر گذرواژه فقط DEK را دوباره بسته‌بندی می‌کند و همه‌چیز را از نو رمزنگاری نمی‌کند.
- مقاومت Argon2id قابل تنظیم: سبک (32 MiB)، استاندارد (64 MiB، مانند Keyra)، تقویت‌شده (128 MiB · ۴ گذر).
- **کلید بازیابی** به سبک Keyra: ‏۳۲ نویسه (base32 کراکفورد، ۱۵۰ بیت + کنترل)، فقط یک بار
  نمایش داده می‌شود؛ «گذرواژه را فراموش کرده‌ام» کلید تازه‌ای می‌سازد و کلید قبلی را باطل می‌کند.
- **زیست‌سنجی**: DEK با یک کلید AES از **Android Keystore** رمزنگاری می‌شود که فقط پس از
  احراز هویت زیست‌سنجی قوی قابل استفاده است و با افزودن اثر انگشت تازه باطل می‌شود.
- **کد PIN** (۴ تا ۱۲ رقم) مشتق‌شده با Argon2id، پس از ۵ خطا غیرفعال می‌شود (قابل تنظیم)، گزینهٔ «پس از راه‌اندازی دوباره،
  گذرواژهٔ اصلی را باز هم بپرس».
- **قفل خودکار** (از فوری تا ۴ ساعت، یا هرگز)، در پس‌زمینه هم؛ **کلیپ‌بورد** پس از
  ۳۰ ثانیه پاک می‌شود (قابل تنظیم) و *حساس* علامت می‌خورد (در پیش‌نمایش Android 13+ پنهان)؛ **صفحهٔ امن** (بدون تصویر صفحه،
  پیش‌نمایش پنهان در برنامه‌های اخیر)؛ پشتیبان‌گیری Android از پوشهٔ برنامه غیرفعال؛ APK نسخهٔ *release*
  (غیرقابل اشکال‌زدایی).
- **پشتیبان‌گیری** خودکار هنگام قفل شدن (اگر گاوصندوق تغییر کرده باشد) در `Documents/Haiku/Sauvegardes`، ۱۰ نسخه نگه داشته می‌شود
  (قابل تنظیم)؛ این نسخه‌ها به‌صورت گاوصندوق **تازه** بازیابی می‌شوند و چیزی بازنویسی نمی‌شود.

### شخصی‌سازی: استودیو و ماژول‌ها
- **۹ تم** (Haïku، Sumi-e، Sakura، نئون، ماتریکس، خورشیدی، یخچال، کاغذی، تک‌رنگ)، حالت‌های تیره، AMOLED،
  روشن و شیشه‌ای، دو رنگ تأکید آزاد (یا هماهنگی تصادفی)، اشتراک تم با کد.
- **پس‌زمینه‌های متحرک**: شفق، صورت فلکی (به انگشت واکنش نشان می‌دهد)، مرکب سومی‌ئه (یک قطره با هر لمس)، گلبرگ‌های
  ساکورا، شبکهٔ رترو، موج‌ها، باران کد؛ شدت، دانه‌بندی کاغذ، هاله.
- **۸ فونت** (Sora، Manrope، Outfit، Space Grotesk، Syne، Unbounded، Shippori Mincho، JetBrains Mono)، گردی گوشه‌ها،
  محوی شیشه، تراکم، فهرست به شکل کارت / ردیف / شبکه، حروف اول یا آیکون.
- **انیمیشن‌های GSAP** قابل تنظیم (هیچ، ملایم، معمولی، *دیوانه‌وار*): آغاز با مهر 俳句، دایرهٔ انسو که با قلم‌مو روی
  صفحهٔ قفل کشیده می‌شود و قفلی که هنگام باز شدن می‌چرخد، آشکار شدن رازها مانند رمزگشایی
  (ScrambleText)، انفجار ذرات (Physics2D)، فهرست‌هایی که خودشان را مرتب می‌کنند (Flip)، پنل‌ها و ردیف‌های قابل کشیدن
  (Draggable + Inertia)، کارت‌هایی که سه‌بعدی کج می‌شوند، گذارهای صفحهٔ دلخواه (لغزش، بزرگ‌نمایی، چرخش سه‌بعدی،
  پرده، محو شدن).
- **ماژول‌ها**: هر قابلیت (2FA، تولیدکننده، سلامت، Send، پوشه‌ها، تاریخچه، سطل زباله، ورود/خروج داده،
  پشتیبان‌ها) روشن یا خاموش می‌شود؛ **نوار زبانه‌ها** را خودتان می‌چینید (حداکثر ۵، مرتب‌سازی با کشیدن)؛ **صفحهٔ اصلی**
  از ویجت‌های قابل جابه‌جایی ساخته شده است (هایکوی روز، جست‌وجو، میان‌برها، علاقه‌مندی‌ها، کدهای 2FA، امتیاز سلامت،
  موارد اخیر، تولیدکنندهٔ سریع، آمار، پوشه‌ها، ابر برچسب‌ها).
- **پالت فرمان** (کشیدن به پایین روی سربرگ، یا Ctrl+K با صفحه‌کلید) و میان‌برهای صفحه‌کلید
  (Ctrl+N، Ctrl+L، Ctrl+G، Ctrl+F، Ctrl+,).

## محدودیت‌های شناخته‌شده
- همگام‌سازی، سازمان‌ها و دسترسی اضطراری وجود ندارد (این‌ها قابلیت‌های سرور Bitwarden هستند): این
  یک گاوصندوق محلی است، مانند Keyra. برای رفتن از یک گوشی به گوشی دیگر: نسخهٔ پشتیبان `.haiku` یا خروجی رمزنگاری‌شده.
- کلیدهای عبور (passkey) موجود در خروجی Bitwarden وارد نمی‌شوند: Haiku ارائه‌دهندهٔ کلید عبور نیست.
- رابط فقط به زبان فرانسوی است (Keyra ‏۱۷ زبان دارد).
- پرکردن خودکار از صفحهٔ Haiku می‌گذرد (بدون پیشنهاد درون صفحه‌کلید): یک لمس بیشتر،
  اما هیچ رازی هرگز به‌صورت متن ساده برای سیستم نگه داشته نمی‌شود.
- فایل‌های `.kdbx` مستقیم خوانده نمی‌شوند: آن‌ها را از KeePassXC / KeePass به CSV یا XML خروجی بگیرید.
- برآورد قدرت گذرواژه آفلاین و تقریبی است.

## ساختن توسط خودتان (Windows، Android Studio، JDK 21)
```bash
npm install
npm test                 # آزمون‌های هسته (رمزنگاری، ورود/خروج داده، 2FA…)
npm run android:add      # فقط اگر پوشهٔ android/ وجود ندارد
npm run sync             # ساخت وب + کپی در پروژهٔ Android + تنظیمات Haiku
npm run open             # Android Studio را باز می‌کند (یا: cd android && gradlew assembleRelease)
```
APK با کلید موجود در `signing/` امضا می‌شود، درست مانند نسخهٔ GitHub Actions: هر کدام روی دیگری
نصب می‌شود.

## سازمان‌دهی کد
```text
src/core/      رمزنگاری، گاوصندوق، واردکننده/خروجی‌گیرها، TOTP، تولیدکننده، قدرت، ممیزی، Send، SSH
src/views/     صفحه‌ها (خانه، گاوصندوق، مورد، ویرایش، 2FA، تولیدکننده، سلامت، Send، استودیو، ماژول‌ها…)
src/ui/        جلوه‌های GSAP، پس‌زمینه‌های متحرک، تم، اجزا، صفحهٔ قفل
scripts/       تنظیمات پروژهٔ Android، افزونهٔ بومی Java (زیست‌سنجی Keystore، صفحهٔ امن، پرکردن خودکار)، آیکون‌ها
tests/         آزمون‌های Node (با یک خروجی واقعی Keyra) و آزمون رابط با Playwright
```

## قدردانی
Haiku یک بازنویسی مستقل است: **قابلیت‌های** Bitwarden و Keyra را بازسازی می‌کند و
**قالب‌های خروجی** آن‌ها را می‌خواند و می‌نویسد، بی‌آنکه از کدشان استفاده کند. سپاس از [GSAP](https://gsap.com) (Webflow)، [Lucide](https://lucide.dev)
(ISC)، [hash-wasm](https://github.com/Daninet/hash-wasm) (MIT)، [jsQR](https://github.com/cozmo/jsQR) (Apache-2.0)،
[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT)، فهرست واژه‌های
[EFF](https://www.eff.org/dice) (CC BY 3.0)، [diceware-wordlists-fr](https://github.com/mbelivo/diceware-wordlists-fr)
(برگرفته از Lexique 3.81)، و فونت‌های Sora، Manrope، Outfit، Space Grotesk، Syne، Unbounded، Shippori Mincho و
JetBrains Mono (SIL Open Font License).
