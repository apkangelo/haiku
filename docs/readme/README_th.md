# Haiku

ตัวจัดการรหัสผ่านแบบ **ออฟไลน์** สำหรับ Android: รวมฟีเจอร์ของ [Bitwarden](https://bitwarden.com) และ
[Keyra](https://github.com/Tahir-1907/Keyra) ไว้ในแอปมือถือเดียว พร้อมแอนิเมชัน GSAP ทุกที่ และอินเทอร์เฟซ
ที่ปรับแต่งได้ทั้งหมดผ่านโมดูล ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มีการเก็บข้อมูลการใช้งาน: ห้องนิรภัยไม่เคยออกจาก
โทรศัพท์

แพ็กเป็น APK ด้วย [Capacitor](https://capacitorjs.com/) คอมไพล์อัตโนมัติด้วย GitHub Actions และออกแบบมาสำหรับ
Galaxy Z Fold (เมื่อพับ: แถบแท็บ; เมื่อกาง: แถบนำทางทางซ้ายและรายการที่เปิดอยู่ทางขวา)

## ดาวน์โหลด APK

➡️ **[ดาวน์โหลด Haiku (`haiku.apk`)](https://github.com/apk-fold/haiku/raw/main/haiku.apk)** — ไฟล์นี้ยังมีอยู่ในแท็บ
*Releases* พร้อมค่าแฮช SHA-256

1. ดาวน์โหลด `haiku.apk` ลงโทรศัพท์แล้วเปิด
2. อนุญาตการติดตั้งจากแหล่งนี้หาก Android ถาม แล้วแตะ **ติดตั้ง**
3. เมื่อเปิดครั้งแรก: *สร้างห้องนิรภัยของฉัน* (หรือ *กู้คืนข้อมูลสำรอง*)

ทุกเวอร์ชันลงนามด้วย **คีย์เดียวกัน** (โฟลเดอร์ `signing/`): การอัปเดตจะติดตั้งทับ
เวอร์ชันก่อนหน้าโดยไม่ต้องถอนการติดตั้ง จึงไม่สูญเสียห้องนิรภัย คีย์นี้เปิดเผยอยู่ในรีโพซิทอรี: ติดตั้ง Haiku
จากรีโพซิทอรีนี้เท่านั้น หากต้องการคีย์ส่วนตัว ให้เพิ่ม secret `HAIKU_KEYSTORE_B64`, `HAIKU_KEYSTORE_PASSWORD` และ
`HAIKU_KEY_PASSWORD` ใน *Settings › Secrets › Actions* (การเปลี่ยนคีย์ต้องถอนการติดตั้ง: สำรอง
ข้อมูลก่อน)

## Haiku ทำอะไรได้บ้าง

### ห้องนิรภัย
- **รายการ 7 ประเภท**: ข้อมูลเข้าสู่ระบบ, บัตรชำระเงิน (บัตร 3D ที่พลิกดูรหัสความปลอดภัยได้), ข้อมูลประจำตัว, บันทึก
  แบบปลอดภัย, คีย์ SSH (สร้าง Ed25519 ในรูปแบบ OpenSSH), เครือข่าย Wi-Fi (แชร์ด้วย QR code), เซิร์ฟเวอร์ (คัดลอก
  คำสั่ง `ssh`/`sftp`)
- **ที่อยู่หลายรายการต่อข้อมูลเข้าสู่ระบบ** พร้อมกฎการจับคู่ (โดเมน, โฮสต์, ตรงทั้งหมด, regex…),
  **ฟิลด์กำหนดเอง** (ข้อความ, ซ่อน, ใช่/ไม่ใช่), **ไฟล์แนบ** ที่เข้ารหัส (10 MB), **บันทึกย่อ**
- **โฟลเดอร์** (สี, ลากเพื่อเรียงลำดับ), **แท็ก** (20 แท็กต่อรายการ ตามกฎของ Keyra), **รายการโปรด**
- **ค้นหา** โดยไม่สนเครื่องหมายเน้นเสียงและตัวพิมพ์เล็กใหญ่, `#étiquette`, `#"deux mots"`, `type:carte`, `is:fav`, `has:totp`, `in:dossier`
- **ประวัติ**: 20 เวอร์ชันต่อรายการ กู้คืนได้พร้อมเปรียบเทียบก่อน/หลัง; รหัสผ่านเก่า 10 รายการ
- **ถังขยะ** ที่ล้างอัตโนมัติ (7, 30, 90 วัน, 1 ปี หรือไม่ล้าง), **ประวัติรวม** ของการเปลี่ยนแปลง
- **ถามรหัสผ่านหลักซ้ำ** เป็นรายการ (เหมือน Bitwarden), **เลือกหลายรายการ** (ย้าย, รายการโปรด,
  ถังขยะ), **ทำสำเนา**, ท่าทาง: ปัดขวา = คัดลอก, ปัดซ้าย = รายการโปรด, กดค้าง = เมนู
- **ห้องนิรภัยอิสระหลายห้อง** แต่ละห้องมีรหัสผ่านของตัวเอง

### การป้อนอัตโนมัติ
- Haiku เป็น **บริการป้อนอัตโนมัติของ Android** (การตั้งค่า › ป้อนอัตโนมัติ): ในแอปหรือ
  เบราว์เซอร์ แตะช่องกรอกแล้วเลือก "ป้อนด้วย Haiku" ปลดล็อก (ไบโอเมตริกซ์, PIN หรือรหัสผ่าน) แล้วเลือก
  ข้อมูลเข้าสู่ระบบ การจับคู่ใช้กฎของ Bitwarden (โดเมน, โฮสต์, `androidapp://paquet`…) และ
  สามารถจดจำการเชื่อมโยงกับแอปได้ในแตะเดียว
- รหัส 2FA ของข้อมูลเข้าสู่ระบบจะถูกคัดลอกอัตโนมัติสำหรับขั้นตอนถัดไป
- หลังจากเข้าสู่ระบบ Android จะเสนอให้ **บันทึก** (หรืออัปเดต) ข้อมูลเข้าสู่ระบบลงใน Haiku
- Chrome: *การตั้งค่า › ป้อนอัตโนมัติ › ใช้บริการอื่น*

### ตัวยืนยันตัวตน (2FA)
- รหัส **TOTP** (SHA-1/256/512, 6 หรือ 8 หลัก, ช่วงเวลาอิสระ), **HOTP** และ **Steam Guard** แบบสด พร้อม
  วงแหวนนับถอยหลังและรหัสถัดไป
- เพิ่มด้วยการ **สแกน QR code** (กล้องหรือภาพหน้าจอ), ป้อนคีย์เอง หรือลิงก์ `otpauth://`
- นำเข้าข้อมูลส่งออกของ **Google Authenticator** ("โอนบัญชี") และ **Aegis**

### ตัวสร้าง
- รหัสผ่าน (5 ถึง 128 ตัวอักษร, จำนวนตัวเลข/สัญลักษณ์ขั้นต่ำ, ตัดอักขระที่ชวนสับสน, เลือกสัญลักษณ์ได้),
  **วลีรหัสผ่าน** (รายการ 7,776 คำในภาษาฝรั่งเศสและอังกฤษ), **ชื่อผู้ใช้** (คำ, สุ่ม, ที่อยู่
  `moi+xxxx@gmail.com`, โดเมน catch-all), **รหัส PIN** แสดงค่าเอนโทรปีที่แม่นยำและเวลาที่ใช้ถอดรหัส
- ประวัติค่าที่สร้าง เข้ารหัสเก็บไว้ในห้องนิรภัย

### สุขภาพห้องนิรภัย
คะแนนเต็ม 100 และรายงาน: รหัสผ่านที่ **อ่อน**, **ใช้ซ้ำ**, **เก่า** (เกินหนึ่งปี), **ขาดหาย**,
**เว็บไซต์ http://**, **บัตรหมดอายุ** และตามคำขอ: **การรั่วไหล** (Have I Been Pwned, k-anonymity: ส่งเพียง
5 ตัวอักษรของแฮช SHA-1) และ **2FA ที่รองรับแต่ยังไม่ได้เปิด** (รายการจาก 2fa.directory)

### Send (การแชร์แบบเข้ารหัส)
Bitwarden Send ฉบับออฟไลน์: ข้อความหรือไฟล์ (15 MB) จะกลายเป็น **หน้า HTML แบบสมบูรณ์ในตัว** ที่เข้ารหัส
(AES-256-GCM, PBKDF2-SHA256 600,000 รอบ) พร้อมวันหมดอายุ ผู้รับเปิดได้ในทุก
เบราว์เซอร์ด้วยรหัสผ่านที่คุณส่งให้ผ่านอีกช่องทางหนึ่ง

### ความปลอดภัย
```text
รหัสผ่านหลัก ──Argon2id (64 MiB, 3 รอบ, 4 เลน)──► KEK
KEK ──AES-256-GCM──► DEK (คีย์ข้อมูลสุ่ม 256 บิต)
DEK ──AES-256-GCM──► เนื้อหาห้องนิรภัย (JSON แบบบีบอัด)
```
- ไม่มีการจัดเก็บรหัสผ่านหลักเลย การเปลี่ยนรหัสผ่านเพียงห่อ DEK ใหม่โดยไม่ต้องเข้ารหัสทุกอย่างใหม่
- ปรับความแข็งแรงของ Argon2id ได้: เบา (32 MiB), มาตรฐาน (64 MiB เหมือน Keyra), เสริมแกร่ง (128 MiB · 4 รอบ)
- **คีย์กู้คืน** แบบ Keyra: 32 ตัวอักษร (base32 ของ Crockford, 150 บิต + ตัวตรวจสอบ) แสดงเพียง
  ครั้งเดียว; "ลืมรหัสผ่าน" จะสร้างคีย์ใหม่และทำให้คีย์เก่าใช้ไม่ได้
- **ไบโอเมตริกซ์**: DEK ถูกเข้ารหัสด้วยคีย์ AES ของ **Android Keystore** ที่ใช้ได้หลังผ่าน
  การยืนยันตัวตนด้วยไบโอเมตริกซ์ระดับสูงเท่านั้น และจะใช้ไม่ได้หากมีการเพิ่มลายนิ้วมือใหม่
- **รหัส PIN** (4 ถึง 12 หลัก) สร้างด้วย Argon2id ปิดใช้งานหลังผิด 5 ครั้ง (ปรับได้) มีตัวเลือก "ถาม
  รหัสผ่านหลักอีกครั้งหลังรีสตาร์ต"
- **ล็อกอัตโนมัติ** (ตั้งแต่ทันทีถึง 4 ชม. หรือไม่ล็อก) รวมถึงเมื่ออยู่เบื้องหลัง; **คลิปบอร์ด** ถูกล้างหลัง
  30 วินาที (ปรับได้) และทำเครื่องหมายว่า *ละเอียดอ่อน* (ซ่อนในตัวอย่างของ Android 13+); **หน้าจอปลอดภัย** (จับภาพหน้าจอไม่ได้,
  ซ่อนตัวอย่างในแอปล่าสุด); ปิดการสำรองข้อมูลโฟลเดอร์แอปของ Android; APK แบบ *release*
  (ดีบักไม่ได้)
- **สำรองข้อมูล** อัตโนมัติเมื่อล็อก (หากห้องนิรภัยมีการเปลี่ยนแปลง) ไว้ที่ `Documents/Haiku/Sauvegardes` เก็บ 10 ชุด
  (ปรับได้); การกู้คืนจะได้ห้องนิรภัย **ใหม่** ไม่เขียนทับสิ่งใด

### การปรับแต่ง: สตูดิโอและโมดูล
- **9 ธีม** (Haïku, Sumi-e, Sakura, นีออน, เมทริกซ์, สุริยะ, ธารน้ำแข็ง, กระดาษ, ขาวดำ) โหมดมืด, AMOLED,
  สว่าง และกระจก สีเน้นอิสระสองสี (หรือชุดสีแบบสุ่ม) แชร์ธีมด้วยรหัส
- **พื้นหลังเคลื่อนไหว**: แสงออโรรา, กลุ่มดาว (ตอบสนองต่อนิ้ว), หมึกซูมิเอะ (หยดหนึ่งหยดทุกครั้งที่แตะ), กลีบ
  ซากุระ, ตารางย้อนยุค, ระลอกคลื่น, ฝนโค้ด; ความเข้ม, เนื้อกระดาษ, รัศมีเรืองแสง
- **8 ฟอนต์** (Sora, Manrope, Outfit, Space Grotesk, Syne, Unbounded, Shippori Mincho, JetBrains Mono), ความโค้งมุม,
  ความเบลอของกระจก, ความหนาแน่น, รายการแบบการ์ด / แถว / ตาราง, อักษรย่อหรือไอคอน
- **แอนิเมชัน GSAP** ที่ปรับได้ (ไม่มี, นุ่มนวล, ปกติ, *สุดเหวี่ยง*): ฉากเปิดด้วยตราประทับ 俳句, วงเอ็นโซที่วาดด้วยพู่กันบน
  หน้าจอล็อกและแม่กุญแจที่หมุนเมื่อปลดล็อก, การเผยข้อมูลลับแบบถอดรหัส
  (ScrambleText), อนุภาคระเบิด (Physics2D), รายการที่จัดเรียงใหม่เอง (Flip), แผงและแถวที่ลากได้
  (Draggable + Inertia), การ์ดที่เอียงแบบ 3D, การเปลี่ยนหน้าตามที่เลือก (เลื่อน, ซูม, พลิก 3D,
  ม่าน, เบลอ)
- **โมดูล**: ทุกฟีเจอร์ (2FA, ตัวสร้าง, สุขภาพ, Send, โฟลเดอร์, ประวัติ, ถังขยะ, นำเข้า/ส่งออก,
  สำรองข้อมูล) เปิดหรือปิดได้; จัด **แถบแท็บ** เองได้ (ไม่เกิน 5, ลากเพื่อเรียง); **หน้าหลัก**
  ประกอบด้วยวิดเจ็ตที่จัดลำดับใหม่ได้ (ไฮกุประจำวัน, ค้นหา, ทางลัด, รายการโปรด, รหัส 2FA, คะแนนสุขภาพ,
  รายการล่าสุด, ตัวสร้างด่วน, สถิติ, โฟลเดอร์, กลุ่มแท็ก)
- **ชุดคำสั่ง** (ปัดลงบนส่วนหัว หรือกด Ctrl+K บนคีย์บอร์ด) และปุ่มลัดคีย์บอร์ด
  (Ctrl+N, Ctrl+L, Ctrl+G, Ctrl+F, Ctrl+,)

## ข้อจำกัดที่ทราบ
- ไม่มีการซิงค์ องค์กร หรือการเข้าถึงฉุกเฉิน (เป็นฟีเจอร์ของเซิร์ฟเวอร์ Bitwarden): นี่เป็น
  ห้องนิรภัยภายในเครื่องเหมือน Keyra หากจะย้ายจากโทรศัพท์เครื่องหนึ่งไปอีกเครื่อง: ใช้ข้อมูลสำรอง `.haiku` หรือการส่งออกแบบเข้ารหัส
- ไม่นำเข้าพาสคีย์ในไฟล์ส่งออกของ Bitwarden: Haiku ไม่ใช่ผู้ให้บริการพาสคีย์
- อินเทอร์เฟซมีเฉพาะภาษาฝรั่งเศส (Keyra มี 17 ภาษา)
- การป้อนอัตโนมัติต้องผ่านหน้าจอของ Haiku (ไม่มีคำแนะนำในแป้นพิมพ์): ต้องแตะเพิ่มหนึ่งครั้ง
  แต่ไม่มีข้อมูลลับใดถูกเก็บเป็นข้อความธรรมดาให้ระบบเลย
- ไม่อ่านไฟล์ `.kdbx` โดยตรง: ให้ส่งออกเป็น CSV หรือ XML จาก KeePassXC / KeePass
- การประเมินความแข็งแรงคำนวณแบบออฟไลน์และเป็นค่าประมาณ

## คอมไพล์เอง (Windows, Android Studio, JDK 21)
```bash
npm install
npm test                 # ทดสอบแกนหลัก (การเข้ารหัส, นำเข้า/ส่งออก, 2FA…)
npm run android:add      # เฉพาะเมื่อยังไม่มีโฟลเดอร์ android/
npm run sync             # build เว็บ + คัดลอกเข้าโปรเจกต์ Android + การตั้งค่าของ Haiku
npm run open             # เปิด Android Studio (หรือ: cd android && gradlew assembleRelease)
```
APK ลงนามด้วยคีย์ใน `signing/` เหมือนกับที่ GitHub Actions ใช้: จึงติดตั้งทับกันได้
ทั้งสองทาง

## โครงสร้างโค้ด
```text
src/core/      การเข้ารหัส, ห้องนิรภัย, ตัวนำเข้า/ส่งออก, TOTP, ตัวสร้าง, ความแข็งแรง, การตรวจสอบ, Send, SSH
src/views/     หน้าจอ (หน้าหลัก, ห้องนิรภัย, รายการ, แก้ไข, 2FA, ตัวสร้าง, สุขภาพ, Send, สตูดิโอ, โมดูล…)
src/ui/        เอฟเฟกต์ GSAP, พื้นหลังเคลื่อนไหว, ธีม, คอมโพเนนต์, หน้าจอล็อก
scripts/       การตั้งค่าโปรเจกต์ Android, ปลั๊กอิน Java แบบเนทีฟ (ไบโอเมตริกซ์ Keystore, หน้าจอปลอดภัย, ป้อนอัตโนมัติ), ไอคอน
tests/         การทดสอบ Node (ด้วยไฟล์ส่งออกจริงของ Keyra) และการทดสอบอินเทอร์เฟซด้วย Playwright
```
